卢卡斯定理是说 $\binom{n}{m}=\binom{\lfloor n/p \rfloor}{\lfloor m/p \rfloor}\binom{n\%p}{m\%p} \pmod p$
用起来简单，证明比较麻烦。

设 $n=ap+b(0\le b<p)$。
这里 $a=\lfloor \frac{n}{p} \rfloor$，$b=n\%p$。
观察形式幂级数 $(1+x)^n$ 的二项式展开：
$(1+x)^n=(1+x)^{ap+b}=(1+x)^{ap}(1+x)^{b}=((1+x)^{p})^{a}(1+x)^{b} \\
=(1+x^p)^{a}(1+x)^{b}=\sum \binom{a}{i}x^{pi}*\sum \binom{b}{j}x^{j}$
上式用到了一个性质，在 $p$ 为素数时：$(1+x)^p=\sum \binom{p}{i}x^i=1+x^p \pmod p$，中间 $\binom{p}{i}$ 都有 $p$ 因子所以模掉了。
此外用最直接的展开 $(1+x)^n=\sum \binom{n}{i}x^i$
对比上面两种 $(1+x)^n$ 的展开方式，考察 $x^m$ 的系数。
故 $\binom{n}{m}=\binom{a}{i}\binom{b}{j}$，且满足 $pi+j=m$。
$i=\lfloor \frac{m}{p} \rfloor$，$j=m\%p$
故 $\binom{n}{m}=\binom{n/p}{m/p}\binom{n\%p}{m\%p}$。

扩展卢卡斯定理：
如果模数不为素数，则前面的做法不成立，主要是在二项式展开模 $p$ 那里并不能确保中间项为 $0$。
但可以将模数进行因数分解，如果所有的素因子的幂都是 $1$，可以分别做卢卡斯，再按中国剩余定理合并。
如果有某个素数因子的幂次大于 $1$，则比较麻烦，需要对每个 $p^e$ 做扩展卢卡斯再用 CRT 合并，这里 $p^e$ 是单个素数 $p$ 在模数中的积。

按定义，$\binom{n}{m}=\frac{n!}{m!(n-m)!}$，我们可以先求出三个阶乘，
但是注意，分子分母都可能含有因子 $p$，直接取模会因为与 $p^e$ 不互质而出问题，所以要把 $p$ 因数单独处理。
求 $x$ 阶乘的时候，可以先预处理 $p^e!$，如果 $x$ 小于 $p$ 可以直接获取结果。
这里需要注意由于 $p$ 因子需要单独处理，这里记录的是不含 $p$ 因子的数的阶乘。
如果 $x$ 很大，需要把 $p$ 的倍数和非倍数分别处理：
不能被 $p$ 整除部分可以用威尔逊定理处理。根据威尔逊定理，在 $1 \sim p^e-1$ 之中与 $p^e$ 不互素的数连乘模 $p^e$ 等于 $-1$。因而其结果为 $(-1)^{\lfloor \frac{n}{p^e} \rfloor}$。剩余部分由于已经小于 $p^e$，可以直接调用预处理阶乘结果。
能被 $p$ 整除的部分可以递归处理。将 $p,2p,3p...$ 这些数提出一个 $p$ 之后，剩下部分依次为 $1,2,3,...\lfloor \frac{x}{p} \rfloor$。但是注意，这里不用真的提 $p$，由于 $p$ 因子不与 $p^e$ 互质，统一在后面处理。
```cpp
void calcFac(ll p, ll pp) {
    for (int i = 1; i < pp; i++) facPE[i] = facPE[i - 1] * (i % p ? i : 1) % pp;
}
ll largeFac(ll n, ll p, ll pp) {
    if (n < p) return facPE[n];
    return facPE[n % pp] * (n / pp & 1 ? pp - 1 : 1) % pp * largeFac(n / p, p, pp) % pp;
}
```
求出三个阶乘之后，通过欧拉定理把 $m!(n-m)!$ 倒过来：
$\frac{1}{m!(n-m)!}=(m!(n-m)!)^{\phi(p^e-1)}$。
对于分子分母的 $p$ 因子，此时直接对分子分母分别计数，得到约分后还有几个。
```cpp
int get(ll n, ll p) {
    int ret = 0;
    while (n) ret += n /= p;
    return ret;
}
ll exlucas(ll n, ll m, ll p, ll pp) {
    ll phi = pp / p * (p - 1), cntP = get(n, p) - get(m, p) - get(n - m, p);
    ll a = largeFac(n, p, pp);
    ll b = largeFac(m, p, pp);
    ll c = largeFac(n - m, p, pp);
    ll d = qp(b * c % pp, phi - 1, pp);
    ll e = qp(p, cntP, pp);
    return a * d % pp * e % pp;
}
```

求出对各个 $p^e$ 取模的结果，再用剩余定理合并即得答案。

# min25

min25 筛可以在亚线性时间内求出 $n$ 以内的积性函数前缀和，简单应用可以求出素数个数/素数和。
其基本思想是运用埃氏筛和动态规划的思路。
记 $g(n,j)$ 表示 $2 \sim n$ 中，素数以及最小素因子大于 $p_j$ 的数的个数。最终目标就是求 $g(n,t)$，这里 $t$ 是 $\sqrt n$ 以内最大的素数编号。
首先令 $g(n,0)=n-1$。因为 $2 \sim n$ 要么是素数，要么是合数，合数的最小素因子一定大于 $0$，所以一共有 $n-1$ 个数满足要求。
之后计算 $g(n,1)$，这代表 $n$ 以内的素数以及最小素因子大于 $p_1=2$ 的合数，那么只需要在 $g(n,0)$ 的基础上扣掉最小素因子为 $2$ 的合数即可。扣除这部分实际等于 $g(n/2,0)$，即将 $n/2$ 以内的全部素数以及最小素因子大于 $0$ 的合数全部乘以 $2$。
之后计算 $g(n,2)$，这代表 $n$ 以内的素数以及最小素因子大于 $p_2=3$ 的合数，那么只需要在 $g(n,1)$ 的基础上扣掉最小素因子为 $3$ 的合数即可。扣除这部分实际等于 $g(n/3,1)-1$，即将 $n/3$ 以内的全部素数以及最小素因子大于 $2$ 的合数全部乘以 $3$，扣除 $2\times 3=6$ 这个数。
...
之后计算 $g(n,t)$，这代表 $n$ 以内的素数以及最小素因子大于 $p_t$ 的合数（其实就是 $n$ 以内所有素数了），那么只需要在 $g(n,t-1)$ 的基础上扣掉最小素因子为 $p_t$ 的合数即可。扣除这部分实际等于 $g(n/p_t,t-1)-(t-1)$，即将 $n/p_t$ 以内的全部素数以及最小素因子大于 $p_{t-1}$ 的合数全部乘以 $p_t$，扣除 $p_1p_t,p_2p_t...p_{t-1}p_t$ 这 $t-1$ 个最小素因子小于 $p_t$ 的数（即前 $t-1$ 个素数与第 $t$ 个素数的乘积）。

直接暴力显然不行，因为计算 $g(n,t)$ 时需要知道 $g(n,t-1)$ 和 $g(n/p_t,t-1)$ 的结果，这会形成递归处理二维数据，数据规模会很大。
但是注意对任意 $n/p_j$ 只有 $O(\sqrt{n})$ 个取值，可以根号分治。简单理解就是 $y=n/x$，那么 $x,y$ 必有一个小于 $\sqrt{n}$，所以不同的 $n/x$ 结果小于 $2\sqrt{n}$ 种，可以以小的一个为依据记录结果。
比如 $g1(x,j)$ 记录 $x \le \sqrt{n}$ 的结果，$g2(n/x,j)$ 记录 $x > \sqrt{n}$ 的结果。实际也可以只开一个 $g$，但是记录一下各个商对应 $g$ 中的编号。
特别注意，对于根号分治来说，虽然同一个商 $n/x$ 代表了一系列的 $x$ 值，而显然不同的 $x$ 值会有不同的 $g$ 值，且不存在常见的诸如预处理前缀和等特性，似乎很难处理。但这里对于 $x > \sqrt{n}$ 的部分，$g2(n/x,j)$ 实际只需要记录 $\lfloor x=\frac{n}{c} \rfloor$ 的那些特殊点，因为只有这些点的结果才会在后续dp中被用到。实际上是通过用小因子编号的方式来分别记录了 $n/1,n/2,n/3...n/i...n/n$ 的结果（在根号分治意义下的），对于商小于 $\sqrt{n}$ 的部分直接用商 $n/i$ 编号，对于商大于 $\sqrt{n}$ 的部分采用 $n/(n/i)$ 编号。其实也可以直接用map来记录这些大于 $\sqrt{n}$ 的点，但是会多个 $log$。
由于计算 $g(x,j)$ 需要用到 $g(x,j-1)$ 和 $g(x/p_j,j-1)$，可以按 $j$ 从小到大计算，并按 $x$ 从大到小计算。这样可以把数组压缩到一维。

具体操作为先做一个欧拉筛，记录各个素数以及各个素数的平方。
```cpp
ll p[N], p2[N], seg[N], g[N];
bool mk[N];
int id1[N], id2[N], ct, sqt;
void pre(int n) {
    for (int i = 2; i <= n; i++) {
        if (!mk[i]) p[++ct] = i, p2[ct] = 1ll * i * i;
        for (int j = 1; p[j] * i <= n; j++) {
            mk[p[j] * i] = true;
            if (i % p[j] == 0) break;
        }
    }
}
```

首先处理各个块：
$l$ 和 $r$ 框定在 $n/x$ 中商为同一个 $c$ 的分母 $x$ 的范围。
$seg_i$ 表示第 $i$ 块记录的范围为 $1 \sim c$，对应前述 $x/p_j$。
$g_i$ 记录第 $i$ 块对应的范围内有几个素数以及最小素因子大于 $0$ 的合数有 $c-1$ 个，即扣除 $1$ 既不是素数也不是合数。
$id1$ 和 $id2$ 用来记录 $g(x,j)$ 里不同 $x$ 对应在分块后的 $g$ 数组中的存放位置。其中 $id1$ 是普通数组一样正常存放的，而 $id2$ 按商值存放（主要原值太大，但是商值小于 $\sqrt{n}$，可以方便存下）。
如果 $c \le \sqrt{n}$，把编号 $m$ 直接写入 $id1_c$，否则写入 $id2_{n/c}$。

接着开始筛(dp)：
回顾转移方程，以及前述对数组的记录方式：
$g(x,j)=g(x,j-1)-(g(x/p_j,j-1)-j+1)$，对于求 $g(n,t)$ 而言，$g(x/p_j,j)$ 中 $x/p_j$ 的取值如果小于等于 $\sqrt{n}$，则直接记录在了 $id1$，若 $x/p_j$ 的取值大于 $\sqrt{n}$，由于只会用到 $n/(p_j...p_k)$ 这种 $n$ 除以某个数的位置，也被记录在了 $id2$。所以当我们划分好根号区间后，所有的必要的区间就都得到了。
```cpp
void solve() {
    ll n;
    int m = 0;
    cin >> n;
    sqt = sqrtl(n), pre(sqt + 300);
    for (ll l = 1, r; l <= n; l = r + 1) {
        ll c = n / l;
        r = n / c;
        seg[++m] = c;
        g[m] = c - 1;
        if (c <= sqt)
            id1[c] = m;
        else
            id2[r] = m;
    }
    for (int j = 1; j <= ct; j++) {
        for (int i = 1; p2[j] <= seg[i]; i++) {
            ll c = seg[i] / p[j];
            c = c <= sqt ? id1[c] : id2[n / c];
            g[i] -= (g[c] - j + 1);
        }
    }
    cout << g[1];
}
```
复杂度分析：第一部分欧拉筛预处理复杂度为 $O(n^{1/2})$，根号分块也为 $O(n^{1/2})$。
后续 dp 部分：外层是素数数量，根据素数密度是 $log$ 级，外层复杂度为 $O(\frac{n^{1/2}}{log(n^{1/2})})=O(\frac{n^{1/2}}{logn})$；内层 $i$ 的极限是段数，为 $\sqrt{n}$，所以复杂度不高于 $O(\frac{n}{logn})$。但是实际上随着 $j$ 的增大，$p2_j$ 会增大，内层循环 $seg_i$ 很快会不满足条件。
对于某个确定的 $p$，内层循环实际是看有多少个区间 $seg_i \ge p^2$，即 $\frac{n}{x} \ge p^2$，即 $x \le \frac{n}{p^2}$。看起来对每个素数 $p$，像是需要枚举 $\frac{n}{p^2}$ 个点值，但是其实我们需要的只是商不同的 $x$ 取值，这其实不超过 $\frac{n}{p^2}$ 个。下面是一个错误的分析：考虑到分块后 $\frac{n}{p^2}$ 的取值只有 $\sqrt{\frac{n}{p^2}}$ 个。
$\sum \sqrt{n}/p=\sqrt{n}\sum 1/p$。
现在将求和转为积分，将离散量乘以密度乘以积分变量。考虑到规模为 $x$ 处的素数的密度为 $\frac{1}{lnx}$。
$\sqrt{n}\sum 1/p=\sqrt{n}\int \frac{1}{x}\frac{1}{lnx}dx=\sqrt{n}\int \frac{1}{lnx}dlnx=\sqrt{n}lnlnn$
这里有个小bug，原来的分块是按照 $n$ 来分的，但是在处理 $\frac{n}{p^2}$ 的时候如果要保证根号复杂度需要按照 
$\frac{n}{p^2}$ 分块，事实上不成立。

事实上，由于按 $n$ 分块，在数值较小时，分块会很密，比如 $n=10000$，则在 $1 \sim 100$ 范围内每个块都只有一个点，如果处理 $50$ 这样的数据，实际上需要看 $50$ 个块而非 $O(\sqrt{50})$ 左右的块。
一个比较保守的估计可以按 $p \le n^{1/4}$ 和 $p>n^{1/4}$ 进行。
对于 $p \le n^{1/4}$ 的部分，$x=n/p^2>n^{1/2}$，涵盖了所有小值区间和部分大值区间，无论如何区间总数不超过 $\sqrt{n}$，因此复杂度实际是 $O(n^{1/2}\frac{n^{1/4}}{log{n^{1/4}}})=O(\frac{n^{3/4}}{logn})$。其中后者为 $n^{1/4}$ 范围内的素数个数。
对于 $p > n^{1/4}$ 的部分，$x=n/p^2<n^{1/2}$，所有块都只有一个点，单点复杂度实际是 $O(n/p^2)$，转成积分，结果为
$\sum \frac{n}{p^2}=\int \frac{n}{x^2}\frac{1}{lnx}dx$
这里由于 $x$ 的变化范围为 $n^{1/4} \sim n^{1/2}$，$lnx$ 只差一个常数，即最好最坏估计复杂度一样，故 $lnx$ 可看作 $lnn$ 提到积分外面，故：
$\int \frac{n}{x^2}\frac{1}{lnx}dx=\frac{n}{lnn}\int \frac{1}{x^2}dx=\frac{n}{lnn}(\frac{1}{n^{1/4}}-\frac{1}{n^{1/2}})=\frac{n^{3/4}}{lnn}$
综合两部分，总体复杂度上界为 $O(\frac{n^{3/4}}{lnn})$。

当然，如果是要求素数之和，那么需要改几个地方：
一：求出素数前缀和 $s_i = s_{i-1} + p_i$。
二：$g(x,j)$ 保存 $x$ 以内的素数与最小素因子大于 $p_j$ 的合数之和 $g_m = (c + 1) * c / 2 - 1$。
三：计算 $g(x,j)$ 的逻辑产生变化。$g(x,j)$ 表示 $x$ 以内，素数以及最小素因子大于 $p_j$ 的合数之和，等于 $x$ 以内，素数以及最小素因子大于 $p_{j-1}$ （亦即大于等于 $p_j$） 的合数之和扣除**最小素因子正好是 $p_j$ 的合数之和**。前者就是 $g(x,j-1)$。
后者对应的数可以用 $x/p_j$ 以内的某些数通过乘以 $p_j$ 使得得到的合数的最小素因子是 $p_j$。这些数应该满足的性质就是原先的素数大于等于 $p_j$，原先的合数的最小素因子大于等于 $p_j$。这样的数近似于 $g(x/p_j,j-1)$，合数部分是一致的，不过素数部分需要扣除小于 $p_j$ 的那些素数（$p_1,p_2,...,p_{j-1}$ 这些数乘上 $p_j$ 后，得到的合数的最小素因子小于 $p_j$）。
即 $g(x,j)=g(x,j-1)-p_j*(g(x/p_j,j-1)-s_{j-1})$。


如果要求积性函数前缀和，类似地可以用 $S(n,j)$ 表示 $n$ 范围内的最小素因子大于 $p_j$ 的位置的积性函数之和。最终就是要求 $S(n,0)$。
$S(n,j)$ 包含两部分，一部分是素数的贡献，一部分是合数的贡献。用 min25 筛第一部分操作可以快速处理出 $n$ 以内素数位置的前缀和，其结果就是 $g(n,t)$ 扣除前 $j$ 个素数的和。对于其中的合数部分可以在其最小素因子 $p_k(k>j)$ 处计算贡献 $f(p_k^eq)=f(p_k^e)f(q)$。所有能以这种形式并入的数据为 $S(n/p_k^e,k)$，即将 $n/p_k^e$ 以内的且最小素因子大于 $p_k$ 的数全部乘上 $p_k^e$ 得到 $n$ 以内的，最小素因子大于 $p_j$ 的数，注意当 $e \ne 1$ 时，$p_k^e$ 本身也是一个结果，而 $p_k^1$ 作为素数已经在前面批量处理过了。
这样，为了求 $S(x,j)$，需要递归调用 $S(x/p_k^e,k)$，第一个参数会变小，第二个参数会变大，难以直接线性递推，不过可以采取递归求解。

第二维为素数个数 $\frac{n^{1/2}}{lnn}$，从递归进入的条件分析，第一维 $x$ 需满足 $x \ge p_k^2$，与第一部分处理 $g$ 数组类似，所以总状态数为$\frac{n^{3/4}}{lnn}$。又由于递归最内层操作对应于进入一个状态，每个状态**近似看作**只会被进入一次，所以复杂度为 $\frac{n^{3/4}}{lnn}$
假设规模 $n$ 从不同路线 $n/a,n/b$ 分别缩减到了 $x$，则必然有 $a,b>\sqrt{n}$，否则 $a,b$ 作为分母稍有不同商就不同。此时说明 $x$ 已经下降到了 $\sqrt{n}$ 以内。因此即便能够冲突到一样的 $x$，每重复一轮会开一个根号，数据规模下降很快，再考虑到 $p_j$ 越来越大会导致提前返回，递归深度不会很深。平均来看进入次数可视为常数。

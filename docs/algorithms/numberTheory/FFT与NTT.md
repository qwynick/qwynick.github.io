FFT 主要是用于求解多项式卷积。
即对于 $A(x)=a_0+a_1x+a_2x^2+a_3x^3+a_4x^4+...a_nx^n$ 以及 $B(x)=b_0+b_1x+b_2x^2+b_3x^3+b_4x^4+...+b_mx^m$ 求 $C(x)=A(x)B(x)$ 各项的系数。
正常用二重循环将 $A(x)$ 和 $B(x)$ 的各项系数乘起来非常直接，但是复杂度会去到 $O(nm)$。

但是多项式除了用上述系数表示外，还可以直接用点表示。即对于一个 $n$ 次多项式，只需要给出 $n+1$ 个点即可确定。比如 $2$ 个点确定一个一次多项式，$3$ 个点确定一个二次多项式。从点还原到系数其实就是解 $n+1$ 元线性方程组问题。

但是如果我们用点来表示多项式，当我们求两个多项式乘积的时候，$C(x_0)=A(x_0)B(x_0)$ 只需要将两个数值简单乘起来即可。即是说，在点表示法下，多项式的乘法将是线性复杂度的。

现在问题就是如何才能快速将系数表示转为点表示。如果直接随意选取 $x_0,...x_n$，每个点的计算都是 $O(n)$ 的，即将系数表示转为点表示的复杂度会去到 $n^2$，不如直接按系数表示法计算。

FFT 可以实现快速的系数变换，将复杂度降到 $nlogn$。
这里主要用到了一些对称性质。比如 $y=x+x^2$，由于 $f(x)=x$ 为奇函数因此很容易知道 $f(x)=-f(-x)$；$g(x)=x^2$ 为偶函数，所以很容易知道 $g(x)=g(-x)$。所以如果算过了 $f(x)$ 和 $g(x)$，那么 $f(-x)$ 和 $g(-x)$ 是不用算的，可以用 $f(x)$ 和 $g(x)$ 组合出 $y(x)$ 和 $y(-x)$。比如 $y(x)=f(x)+g(x)$，$y(-x)=-f(x)+g(x)$。
当然，上述只取正负的操作只能快速求解一个二次的多项式。

为了能够求解更高次的多项式，FFT 会运行在 $n=2^m$ 次单位根上，寻找在这个系统中的对称性。
设 $w_n^k=e^{2k\pi i/n}$。$k$ 的取值范围为 $0\le k <n$。
这里有几个性质
$w_{2n}^{2k}=e^{2(2k)\pi i/(2n)}=e^{2k\pi i/n}=w_{n}^{k}  \Longleftrightarrow w_{n}^{k}=w_{k/2}^{n/2}$ 
$w_{2n}^{k+n}=e^{2(k+n)\pi i/(2n)}=e^{2k\pi i/(2n)}e^{i\pi}=-w_{2n}^{k} \Longleftrightarrow w_{n}^{k+n/2}=-w_{n}^{k}$

现在开始做变换，取 $x_k=w_{n}^{k}=e^{2k\pi i/n}$。
现在计算 $A(x_0),A(x_1)...A(x_{n-1})$。
$A(x)=a_0+a_1x+a_2x^2+a_3x^3+a_4x^4+...a_{n-1}x^{n-1}=(a_0+a_2x^2+a_4x^4...)+x(a_1+a_3x^2+a_5x^4+...)$
观察上面这个式子，对于 $A(x_k)$ 和 $A(x_{k+n/2})$，他们相差一个负号，因此其两个括号内部的结果其实是一样的，不过第二个括号外面多一个 $x$，因此差个负号。所以其实我们只需要分别求出两个括号在 $x_k$ 处的取值，再加减组合一下就得到了 $A(x_k)$ 和 $A(x_{k+n/2})$ 的结果。这也是 FFT 加速的本质，通过选取一些特别的 $x$，使得其他一些点的函数值能够快速计算。
为了求得左边括号的结果，可以对左边括号继续拆解，为方便观察，令 $y_k=x_k^2=x_{k+n/2}^2=w_{n}^{2k}=w_{n/2}^k$：
$a_0+a_2y+a_4y^2+a_6y^3+...=(a_0+a_4y^2+a_8y^4+...)+y(a_2+a_6y^2+a_{10}y^4+...)$
注意到对于 $y_k$ 和 $y_{k+n/4}$ 只差负号，因此两个括号的结果是一样的，唯一不同的是第二个括号前的 $y$，所以可以分别求出两个括号的结果，然后正负组合一下就能得到结果。
所以我们不断递归，然后在返回时将两边的结果进行组合，即可求到整个 $A(x_0),A(x_1)...A(x_{n-1})$。

```cpp
void fft(Comp d[], int tot, int sgn) {
    if (tot == 1) return;
    int tot2 = tot / 2;
    Comp d1[tot2], d2[tot2];
    for (int i = 0; i < tot2; i++) d1[i] = d[2 * i], d2[i] = d[2 * i + 1];
    fft(d1, tot2, sgn), fft(d2, tot2, sgn);
    Comp w1{cos(pi2 / tot), sin(pi2 / tot) * sgn}, wk = {1, 0};
    for (int i = 0; i < tot2; i++) {
        d[i] = d1[i] + d2[i] * wk;
        d[i + tot2] = d1[i] - d2[i] * wk;
        wk = wk * w1;
    }
}
```
整个过程类似于归并排序，由于递归深度是 $logn$ 层，复杂度也是 $O(nlogn)$ 的。
以 $A(x)=a_0+a_1x+a_2x^2+a_3x^3+a_4x^4+a_5x^5+a_6x^6+a_7x^7$ 为例，记 $8$ 次单位根为 $w$，手推一下计算过程：
递归的第一层：$A_l(x)=a_0+a_2x^2+a_4x^4+a_6x^6$ 分为一组递归，$A_r(x)=x(a_1+a_3x^2+a_5x^4+a_7x^6)$ 分为一组递归。此时，我们要同时计算的是 $w_8^i$ 和 $w_8^{i+4}$，即差 $4$ 的两对数，前加后减，同时，后者还要乘上一个系数 $x=w_8^i$。
比如要计算 $i=3,7$，我们需要递归计算 $A_l(x^3)$ 和 $A_r(x^3)$，然后就能凑出 $A(x^3)=A_l(x^3)+x^3A_r(x^3)$ 以及 $A(x^7)=A_l(x^7)+x^7A_r(x^7)=A_l(x^3)+x^7A_r(x^3)=A_l(x^3)-x^3A_r(x^3)$。
递归的第二层：$a_0+a_4x^4$ 分为一组递归，$x^2(a_2+a_6x^4)$ 分为一组递归。$a_1+a_5x^4$ 分为一组递归，$x^2(a_3+a_7x^4)$ 分为一组递归。此时，我们要同时计算的是 $w_4^i$ 和 $w_4^{i+2}$，即差 $2$ 的两对数，前加后减，同时，后者还要乘上一个系数 $x^2=(w_8^i)^2=w_4^i$。
比如要计算 $i=1,3$，我们需要递归计算 $A_l(x^1)$ 和 $A_r(x^1)$，然后就能凑出 $A(x^1)=A_l(x^1)+x^2A_r(x^1)$ 以及 $A(x^3)=A_l(x^3)+x^6A_r(x^3)=A_l(x^1)+x^6A_r(x^1)=A_l(x^1)-x^2A_r(x^1)$。
递归的第三层：$a_0,x^4a_4,a_2,x^4a_6,a_1,x^4a_5,a_3,x^4a_7$ 各自分为一组递归。此时，我们要同时计算的是 $w_2^i$ 和 $w_{i+1}$，即差 $1$ 的两对数，前加后减，同时，后者还要乘上一个系数 $w_2^i$。
递归的第四层：只有一个元素，直接返回。
返回的第三层：
区分关于 $w_8^4$ 呈现奇偶性的项。如果单位根差 $2k+1$，幂次差 $8k+4$，凑出 $-1$；如果单位根差 $2k$，幂次差 $8k$，可以凑出 $1$。
单位根 $0246$ 用到的系数分别变为：$a_0+a_4,a_2+a_6,a_1+a_5,a_3+a_7$；
单位根 $1357$ 用到的系数分别变为：$a_0-a_4,a_2-a_6,a_1-a_5,a_3-a_7$；
注意这里的系数是指特定的关系，即在 $w_n^0,w_n^2,w_n^4,w_n^6$ 的作用下 $a_0,a_4$ 同号；
注意这里的系数是指特定的关系，即在 $w_n^1,w_n^3,w_n^5,w_n^7$ 的作用下 $a_0,a_4$ 异号。
虽然这并不是最终结果，但是幂次的差异确保了各个系数的符号关系。最终的系数会在多轮组合中逐渐完成。

返回的第二层：
区分关于 $w_8^2$ 呈现奇偶性的项。如果单位根差 $4k+2$，幂次差为 $8k+4$，凑出 $-1$；如果单位根差 $4k$，幂次差 $8k$，可以凑出 $1$。
上一轮已经区分过 $0246$ 与 $1357$，前者在四次幂作用下同号，后者异号。
现在用 $w_8^2$ 进一步区分。
上一轮中已得知，$0246$ 用到的是这些的组合：$a_0+a_4,a_2+a_6,a_1+a_5,a_3+a_7$；
对于 $04$ 来说，$a_0$ 与 $a_2$ 差 $2$，$a_1$ 与 $a_3$ 差 $2$，单位根为 $4k$，幂次差为 $8k$，结果为 $1$，即同号。
即单位根 $04$ 用到的系数为分别变为: $a_0+a_4+a_2+a_6,a_1+a_5+a_3+a_7$
对于 $26$ 来说，$a_0$ 与 $a_2$ 差 $2$，$a_1$ 与 $a_3$ 差 $2$，单位根为 $4k+2$，幂次差为 $8k+4$，结果为 $-1$，即异号。
即单位根 $26$ 用到的系数为分别变为: $a_0+a_4-(a_2+a_6),a_1+a_5-(a_3+a_7)$
同理：
单位根 $15$ 用到的系数为分别变为: $a_0-a_4+w_8^2(a_2-a_6),a_1-a_5+w_8^2(a_3-a_7)$
单位根 $37$ 用到的系数为分别变为: $a_0-a_4-w_8^2(a_2-a_6),a_1-a_5-w_8^2(a_3-a_7)$
组合时多出来的系数是来自于 $w_8^2i$。

返回的第一层：
区分关于 $w_8^2$ 呈现奇偶性的项。如果单位根差 $8k+4$，幂次差为 $8k+4$，凑出 $-1$；不存在幂次差 $8k$ 的情况，因此无法凑出 $1$。
单位根 $0$ 用到的系数为分别变为: $a_0+a_4+a_2+a_6+(a_1+a_5+a_3+a_7)$

组合时多出来的系数是来自于 $w_8^i$。

经过三轮分组合并，就将各个单位根的函数值算出来了。

对于总长为 $8$ 的情况，其规律为：
每 $8$ 个长度为一个块，块内前一半 $x$ 与 $x+4$ 配对。
每 $4$ 个长度为一个块，块内前一半 $x$ 与 $x+2$ 配对。
每 $2$ 个长度为一个块，块内前一半 $x$ 与 $x+1$ 配对。

不过系数的初始位置需要调整一下，调整方式成为蝴蝶变换，既是把每个数放在二进制逆序的位置上。实际效果是把偶数归到左边，奇数归到右边。
且左边除以 $2$ 后仍然是偶数在左奇数在右；右侧扣除 $1$ 在除以 $2$ 后也是偶数在左奇数在右。
```cpp
for (int i = 0; i < tot; i++) rev[i] = rev[i >> 1] >> 1 | (i & 1) << bit - 1;
```
其逻辑为，一个数的逆序等于去掉最低位后（数变小了，一定计算过），进行翻转再右移一次删去由最高位移到最低位的 $0$，再补上新的最高位。

之后就可以按照区块大小进行原地计算了。
```cpp
void fft(Comp d[], int tot, int sgn) {
    if (tot == 1) return;
    for (int i = 0; i < tot; i++)
        if (i < rev[i]) swap(d[i], d[rev[i]]);
    for (int l = 1; l < tot; l *= 2) {
        Comp w1 = {cosl(pi / l), sinl(pi / l) * sgn};
        for (int i = 0; i < tot; i += l * 2) {
            Comp wk = {1, 0};
            for (int j = 0; j < l; j++) {
                Comp x = d[i + j] + wk * d[i + j + l], y = d[i + j] - wk * d[i + j + l];
                d[i + j] = x, d[i + j + l] = y;
                wk = w1 * wk;
            }
        }
    }
}
```
在求得 $C(x)=A(x)B(x)$ 的点值后，需要还原到 $C(x)$ 的系数表示法，只需要将单位根改成逆向，再做一次 FFT 即可，最后会多一个系数 $n$。
原因是，在做正 FFT 的时候，实质上是通过系数矩阵和 $x_i$ 算出 $y_i$：
$\begin{bmatrix}
1 & 1 & 1 & ... & 1 \\
1 & x & x^2 & ... & x^{n-1} \\
1 & x^2 & x^{2*2} & ... & x^{2*(n-1)} \\
... & ... & ... & ... & ...\\
1 & x^{n-1} & x^{(n-1)*2} & ... & a^{(n-1)(n-1)} \\
\end{bmatrix}
\begin{bmatrix} a_0 \\ a_1 \\ a_2 \\ ... \\ a_{n-1} \end{bmatrix}
\;=\;
\begin{bmatrix} y_0 \\ y_1 \\ y_2 \\ ... \\ y_{n-1} \end{bmatrix}
$
现在已知 $y_i$，要插值出 $a_i$，只要左乘一个逆矩阵即可。
逆矩阵为
$\frac{1}{n}\begin{bmatrix}
1 & 1 & 1 & ... & 1 \\
1 & x^{-1} & x^{-2} & ... & x^{-(n-1)} \\
1 & x^{-2} & x^{-2*2} & ... & x^{-2*(n-1)} \\
... & ... & ... & ... & ...\\
1 & x^{-(n-1)} & x^{-(n-1)*2} & ... & a^{-(n-1)(n-1)} \\
\end{bmatrix}$
左矩阵第 $i$ 行 $x^{-ik}$，右矩阵第 $j$ 列 $x^{kj}$，乘积 $M_{ij}=\sum x^{-ik}x^{kj}=\sum x^{k(j-i)}$。如果 $i=j$，求和结果为 $n$。否则结果为 $\sum x^{(j-i)k}=\frac{x^{(j-i)n}-1}{x^{j-i}-1}=0$。
FFT 由于涉及到浮点数，存在精度误差，long double 极限一般到 $10^{14}$ 就差不多了，如果需要精确的组合计数，会出成 NTT。
在 FFT 中，通过单位根的倍数关系来加速计算点值，NTT 借助原根的倍数关系来加速计算点值。
在 FFT 中，$n$ 次单位根的 $n$ 次方等于 $1$，且更小的幂次都不为 $1$；在 NTT 中，原根的 $p-1$ 次方也等于 $1$，且更小的幂次都不为 $1$。所以也可以把原根抽象成某种平面上转圈。
常见的模数为 $998244353$，存在原根 $3$，且 $p-1=998244352=7*17*2^{23}$。也就是说，我们最多可以做到 $2^{23}$ 次单位根，结果为 $3^{119}$。
设 $n=2^m$，在 FFT 中 $w_n^k=e^{2k\pi i/n}$，在 NTT 中 $w_n^k=3^{998244352k/n}$。
这里 $n$ 最大可以取到 $2^{23}$，即 $2^{23}$ 次单位根。
很好验证他们也满足 $w_{2n}^{2k}=w_n^k$ 和 $w_n^k=w_n^{k+n/2}$。所以具有与 FFT 一样的递推过程。
```cpp
void ntt(ll d[], int tot, int sgn) {
    for (int i = 0; i < tot; i++)
        if (i < rev[i]) swap(d[i], d[rev[i]]);
    for (int l = 1; l < tot; l *= 2) {
        ll g1 = qp(sgn > 0 ? 3 : 332748118, (mod - 1) / l / 2);
        for (int i = 0; i < tot; i += l * 2) {
            ll gk = 1;
            for (int j = 0; j < l; j++) {
                ll x = (d[i + j] + gk * d[i + j + l]) % mod, y = (d[i + j] - gk * d[i + j + l] % mod + mod) % mod;
                d[i + j] = x, d[i + j + l] = y;
                gk = gk * g1 % mod;
            }
        }
    }
    if (sgn == -1) {
        ll invt = qp(tot, mod - 2);
        for (int i = 0; i < tot; i++) d[i] = d[i] * invt % mod;
    }
}
```
做反变换时，需要用 $1/3$，即 $3$ 的逆元。同样需要在最后除以总项数 $n$。

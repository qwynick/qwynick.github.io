欧几里得算法，辗转除法：
要求 $m$ 和 $n$ 的最大公约数。
假定最大公约数为 $g$，即有 $g|n$ 且 $g|m$。
显然 $g|n-m$。
所以 $(n,m)=(n-m,m)=(n-2m,m)=(n-3m,m)...$
所以可以直接一步到位 $(n,m)=(n\%m,m)=(m,n\%m)$，此式可以递归处理 $(m,n\%m)=(n\%m,m\%(n\%m))$，直到正好能整除。此时的非零数即为最大公约数 $g$，也可以理解为上一步 $m'|n'$，此时 $m'$ 即为结果。

扩展欧几里得算法：
可以证明 $nx+my$ 能表示的最小正值为最大公约数 $(n,m)=g$。现在需要进一步求系数 $x,y$ 使得：$nx+my=g$。
很显然，递归的终点 $m=0,n=g$，此时 $n*1+m*0=g$，即 $x=1,y=0$。
现在考虑递归回退时，已知下一层 $nx+my=g$，要求当前层 $n',m'$ 对应的系数$x',y'$。
依题意，应满足 $n'x'+m'y'=g$。
根据辗转除法的递归关系 $(n',m')=(n=m',m=n'\%m')$，
即 $n=m',m=n'\%m'$，代入 $nx+my=g$，可得
$m'x+n'\%m'y=g$
这里 $n'\%m'=n'- \lfloor n'/m' \rfloor m'$ 代入上式：
$m'x+(n'- \lfloor n'/m' \rfloor m')y=g$
$n'y+m'(x- \lfloor n'/m' \rfloor y)=g$
因此当前层的满足 $n'x'+m'y'=g$ 的系数为 $x'=y,y'=x- \lfloor n'/m' \rfloor y$。
此即由下一层的 $x,y$ 推及当前层的 $x',y'$。
```cpp
ll exgcd(ll a, ll b, ll& x, ll& y) {
    if (b == 0) {
        x = 1, y = 0;
        return a;
    }
    ll g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}
```

原始的中国剩余定理：
如果有方程组
$n\%m_1=r_1$
$n\%m_2=r_2$
$n\%m_3=r_3$
满足 $m_1,m_2,m_3$ 两两互质。
令 $m=m_1m_2m_3$。
$u_1=\frac{m}{m_1},u_2=\frac{m}{m_2},u_3=\frac{m}{m_3}$。
显然 $u_1$ 的任何倍数 $\%m_2$ 和 $\%m_3$ 都是 $0$，所以 $u_1$ 的倍数只影响模 $m_1$ 的结果。
可以先求出逆元，即 $c_1u_1=1 \pmod {m_1}$，这样满足 $r_1$ 的系数就是$c_1u_1r_1$。
具体可用扩展欧几里得求解 $u_1x+m_1y=1$。这里由于 $u_1$ 与 $m_1$ 互质，一定有解。
之后结果就是 $(\sum c_iu_ir_i) \%m$

当然，求 $c_1$ 满足 $c_1*u_1=1 \pmod {m_1}$ 其实就是求 $u_1$ 在模 $m_1$ 意义下的逆元，
由于所有的模数互质，因此 $(u_1,m_1)=1$，由欧拉定理，$c_1=u_1^{\phi(m_1)-1}$。

扩展中国剩余定理：
$n\%m_1=r_1$
$n\%m_2=r_2$
$n\%m_3=r_3$
不要求 $m_1,m_2,m_3$ 两两互质。
可以逐项代入最终得到 $m$ 和 $r$。
考虑前面两项已经得到一个 $m$ 和一个 $r$，通解为 $r+mx$，满足 $r+mx=r_1 \pmod{m_1}$，$r+mx=r_2 \pmod{m_2}$。
现在拟并入 $m_3,r_3$，得到一个新的通解 $r'+m'x'$。
按照要求有：$r+mx=r_3 \pmod{m_3}$
稍加变形：$r+mx+m_3y=r_3$
即：$mx+m_3y=r_3-r$
此处必须 $g=(m,m_3)|r_3-r$，否则无解。
在能整除的情况下，通过扩展欧几里得可得到一对 $x_g,y_g$，使得
$mx_g+m_3y_g=g$
两边同时乘以 $\frac{r_3-r}{g}$ 得到
$mx_g\frac{r_3-r}{g}+m_3y_g\frac{r_3-r}{g}=r_3-r$
所以方程 $mx+m_3y=r_3-r$ 的特解为：$x=x_g\frac{r_3-r}{g}$
所以新的特解为 $r'=r+mx$，通解为 $r'=r+mx+m'x'$
显然 $m'=lcm(m,m_3)$

同时注意 $mx_g+m_3y_g=g$ 这个方程，等价于$\frac{m}{g}x_g+\frac{m_3}{g}y_g=1$，故$x_g$ 的取值是可以对 $m_3/g$ 取模的。
```cpp
bool crt(ll& m, ll& r, ll m1, ll r1) {
    ll x, y;
    ll g = exgcd(m, m1, x, y);
    if ((r - r1) % g) return false;
    m1 /= g;
    x = __int128(r1 - r) / g * x % m1;
    r += x * m;
    m *= m1;
    if (r < 0) r += m;
    return true;
}
```

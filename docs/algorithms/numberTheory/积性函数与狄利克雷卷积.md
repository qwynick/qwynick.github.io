# 积性函数与狄利克雷卷积

常见的积性函数：

单位元 $\epsilon(n)=[n=1]$：
$\epsilon(nm)=[nm=1]=[n=1][m=1]=\epsilon(n)\epsilon(m)$

常值函数 $1(n)=1$：
$1(nm)=1=1(n)1(m)$

等值函数 $Id(n)=n$：
$Id(nm)=nm=Id(n)Id(m)$

以下假定 $n=\prod p_i^{a_i}$，$m=\prod q_i^{b_i}$
欧拉函数 $\phi(n)=n\prod(1-\frac1{p_i})$
$\phi(nm)=nm\prod(1-\frac1{p_i})\prod(1-\frac1{q_i})=\phi(n)\phi(m)$

因子个数$\tau$：
$\tau(nm)=\prod(1+a_i)\prod(1+b_i)=\tau(n)\tau(m)$

因子和$\sigma$：
$\sigma(nm)=\prod\frac{p_i^{a_i+1}-1}{p_i-1})\prod\frac{q_i^{b_i+1}-1}{q_i-1})=\sigma(n)\sigma(m)$

莫比乌斯函数$\mu$：
$\mu=\begin{cases}
0 & 任意质因子的次数>1 \\
(-1)^k & 有k个不同质因子
\end{cases}$

积性函数满足交换律、结合律、分配律。
$f*g=g*f$
$(f*g)*h=f*(g*h)$
$f*(g+h)=f*g+f*h$

积性函数的狄利克雷卷积还是积性函数。
设两个积性函数分别为$fg$。
$(f*g)(nm)=\sum f(d)g(nm/d)$
由于 $(n,m)=1$，可以唯一地把 $d$ 拆解为来自 $n$ 和 $m$ 的部分，同时把 $\frac{nm}d$ 也唯一地拆解为分属 $n$ 和分属 $m$ 的部分。
$(f*g)(nm)=\sum\sum f(d_nd_m)g(\frac n{d_n}\frac m{d_m})$
由 $fg$ 都是积性函数且 $(d_n,d_m)=1$，$(\frac n{d_n},\frac m{d_m})=1$，拆开得
$(f*g)(nm)=\sum\sum f(d_n)f(d_m)g(\frac n{d_n})g(\frac m{d_m})$
重新组合一下得：
$(f*g)(nm)=\sum\sum f(d_n)g(\frac n{d_n})f(d_m)g(\frac m{d_m})=\sum f(d_n)g(\frac n{d_n})\sum f(d_m)g(\frac m{d_m})=((f*g)(n))((f*g)(m))$

重要的恒等式：
$1*\mu=\epsilon$
$1*1=\tau \Leftrightarrow 1=\mu*\tau$
$1*\phi=Id \Leftrightarrow \phi=\mu*Id$
$1*Id=\sigma \Leftrightarrow Id=\mu*\sigma$
右侧三个比较抽象，但是可以通过对左边式子两侧乘以 $\mu$ 得到。

运用积性函数在 $p^e$ 处的性质，可以统一完成所有积性函数的计算。
$f(n)=f(p^e)*f(\frac n{p^e})$
当 $n=p^e$ 时，根据实际意义计算 $f(p^e)$ 即可。
否则 $f(\frac n{p^e})$ 和 $n=p^e$ 都已知，可直接读取历史结果乘起来。
```cpp
void pre() {
    f[1] = d[1] = phi[1] = sig[1] = u[1] = 1;
    for (int i = 2; i <= 100; i++) {
        if (!f[i]) p[tot++] = pe[i] = f[i] = i;
        for (int j = 0; p[j] * i <= 100; j++) {
            f[p[j] * i] = p[j];
            if (i % p[j] == 0) {
                pe[i * p[j]] = pe[i] * p[j];
                break;
            }
            pe[i * p[j]] = p[j];
        }
    }
    for (int i = 2; i <= 100; i++)
        if (i == pe[i]) {
            phi[i] = i / f[i] * (f[i] - 1);
            d[i] = d[i / f[i]] + 1;
            sig[i] = sig[i / f[i]] + i;
            u[i] = i == f[i] ? -1 : 0;
        } else {
            phi[i] = phi[i / pe[i]] * phi[pe[i]];
            d[i] = d[i / pe[i]] * d[pe[i]];
            sig[i] = sig[i / pe[i]] * sig[pe[i]];
            u[i] = u[i / pe[i]] * u[pe[i]];
        }
}
```

# FMT与FWT

$C_i=\sum_{j\oplus k=i}A_j×B_k$
这里 $\oplus$ 可以是 &|^，直接计算复杂度会去到 $O(n^2)$。

通过 FWT 可以将复杂度降到 $O(nlogn)$。
先以 | 为例，
考虑 $n=2$，
$C_{0}=A_{0}B_{0}$
$C_{1}=A_{0}B_{1}+A_{1}B_{0}+A_{1}B_{1}$
如果 $A_{0}'=A_{0},A_{1}'=A_{0}+A_{1}$，
如果 $B_{0}'=B_{0},B_{1}'=B_{0}+B_{1}$，
此时 $C_{0}'=A_{0}'B_{0}'=A_{0}B_{0},C_{1}'=A_{1}'B_{1}'=A_{0}B_{0}+A_{0}B_{1}+A_{1}B_{0}+A_{1}B_{1}$
此时 $C_{0}=C_{0}',C_{1}=C_{1}'-C_{0}'$

考虑 $n=4$，最终结果上：
$C_{00}=A_{00}B_{00}$
$C_{01}=A_{00}B_{01}+A_{01}B_{00}+A_{01}B_{01}$
$C_{10}=A_{00}B_{10}+A_{10}B_{00}+A_{10}B_{10}$
$C_{11}=A_{00}B_{11}+A_{01}B_{10}+A_{01}B_{11}+A_{10}B_{01}+A_{10}B_{11}+A_{11}B_{00}+A_{11}B_{01}+A_{11}B_{10}+A_{11}B_{11}$

对于 $A'$，先合并 $A$ 的个位，把个位为 $0$ 的数据合并入对应的个位为 $1$ 的位置。
$A_{00}'=A_{00}$，
$A_{01}'=A_{00}+A_{01}$，
$A_{10}'=A_{10}$，
$A_{11}'=A_{10}+A_{11}$。
再合并 $B$ 的十位，把十位为 $0$ 的数据合并入对应的十位为 $1$ 的位置。
$A_{00}'=A_{00}$，
$A_{01}'=A_{00}+A_{01}$，
$A_{10}'=A_{00}+A_{10}$，
$A_{11}'=A_{00}+A_{01}+A_{10}+A_{11}$。
同理可以得到 $B'$ 的结果。
$B_{00}'=B_{00}$，
$B_{01}'=B_{00}+B_{01}$，
$B_{10}'=B_{00}+B_{10}$，
$B_{11}'=B_{00}+B_{01}+B_{10}+B_{11}$。
将 $A'$ 和 $B'$ 乘起来得到 $C'$。
$C_{00}'=A_{00}B_{00}$，
$C_{01}'=(A_{00}+A_{01})(B_{00}+B_{01})$，
$C_{10}'=(A_{00}+A_{10})(B_{00}+B_{10})$，
$C_{11}'=(A_{00}+A_{01}+A_{10}+A_{11})(B_{00}+B_{01}+B_{10}+B_{11})$。
接下来做逆变换，先消除个位，把个位为 $0$ 的数据从对应的个位为 $1$ 的位置中扣除。
$C_{00}'=A_{00}B_{00}$，
$C_{01}'=A_{00}B_{01}+A_{01}B_{00}+A_{01}B_{01}$，
$C_{10}'=(A_{00}+A_{10})(B_{00}+B_{10})$，
$C_{11}'=(A_{00}+A_{10})(B_{01}+B_{11})+(A_{01}+A_{11})(B_{00}+B_{10})+(A_{01}+A_{11})(B_{01}+B_{11})$。
再消除十位
$C_{00}'=A_{00}B_{00}$，
$C_{01}'=A_{00}B_{01}+A_{01}B_{00}+A_{01}B_{01}$，
$C_{10}'=A_{00}B_{10}+A_{10}B_{00}+A_{10}B_{10}$，
$C_{11}'=A_{00}B_{11}+A_{10}B_{01}+A_{10}B_{11}+A_{01}B_{10}+A_{11}B_{00}+A_{11}B_{10}+A_{01}B_{11}+A_{11}B_{01}+A_{11}B_{11}$。
这就是最终的结果。

FWT 本质上就是对于 $X_{abcd}$ 首先处理 $d$ 位，把所有的 $abc0$ 的数据并入 $abc1$。
之后把所有的 $ab0d$ 的数据并入 $ab1d$，之后把所有的 $a0cd$ 的数据并入 $a1cd$，之后把所有的 $0bcd$ 的数据并入 $1bcd$。
此时 $X$ 的所有 bit 为 $1$ 的位置保存了 bit 为 $0/1$ 的数据。
复杂度 $nlogn$。
之后，$C'=A'B'$，此时的 $C$ 中 bit 为 $1$ 的位置保存的就是该处为 $0/1$ 的数据。
为了让 $1$ 的位只保存 $1$ 的数据，需要再逐位扣除。

首先把所有的 $abc1$ 的数据扣除 $abc0$，之后把所有的 $ab1d$ 的数据扣除 $ab0d$，把所有的 $a1cd$ 的数据扣除 $a0cd$，把所有的 $1bcd$ 的数据扣除 $0bcd$。

FWT 正运算是加，逆运算是减。所以写一个通过参数控制即可。
$len$ 控制的就是配对的bit，一开始 $len=1$ 是个位 $01$；之后是 $len=2$，对应十位的 $01$；之后 $len=4$，对应百位的 $01$。
```cpp
void fwtor(ll a[], int op) {
    for (int len = 1; len < up; len *= 2) {
        int len2 = len << 1;
        for (int st = 0; st < len; st++)
            for (int j = st; j < up; j += len2) a[j + len] = (a[j + len] + a[j] * op) % mod;
    }
    for (int i = 0; i < up; i++) a[i] = (a[i] + mod) % mod;
}
```

参考 | 运算，对于 & 运算，数据会被堆积到 0 处。因此数据会被处理到前面一部分。
```cpp
void fwtan(ll a[], int op) {
    for (int len = 1; len < up; len *= 2) {
        int len2 = len << 1;
        for (int st = 0; st < len; st++)
            for (int j = st; j < up; j += len2) a[j] = (a[j] + a[j + len] * op) % mod;
    }
    for (int i = 0; i < up; i++) a[i] = (a[i] + mod) % mod;
}
```

如果 $(a,p)=1$，对于方程 $a^x=b \pmod p$ 求其解 $x=\log_a b \pmod p$ 叫做离散对数问题。
如果 $a$ 是 $p$ 的原根，则必定有解，否则不一定有解。
由于 $a^{\phi(p)}=1$，故如果方程有解，解的范围为 $0\le x \le p-1$。
所以如果暴力枚举，复杂度为 $O(p)$。
可以采用 BSGS 法求解，复杂度为 $O(\sqrt{p}\log p)$。
具体操作为，令 $m=\lceil \sqrt{p-1} \rceil$。
方程的解可以表示为 $x=im+j$，这里 $0\le i,j \lt m$，对应 $0\le im+j\lt m^2$。
故 $a^{im+j}=b \pmod p$
可以计算出各个 $a^{im}$ 的结果，存入 map，然后再计算 $ba^j$，在 map 中查询 $ba^{-j}$，如果存在，那么就求到了一对 $i,j$ 满足 $a^{im}=ba^{-j}$，即 $a^{im+j}=b$。
这样做需要求 $a^{-1}$。
可以调整一下 $x$ 的拆解方式，$x=im-j$，这里 $1\le i,j \le m$，对应 $0\le im+j\lt m^2$。
与之前一样，可以计算出各个 $a^{im}$ 的结果，存入 map，然后再计算 $ba^j$，在 map 中查询 $ba^j$，如果存在，那么就找到了一对 $i,j$ 满足 $a^{im}=ba^j$，即 $a^{im-j}=b$。
对于 $a$ 非 $p$ 原根的情况，可能有多解，所以需要判一下大小。

如果不保证 $(a,p)=1$，首先可以暴力跑前 $30$ 项，如果没有找到解，提取公因数后一定互素，剩下的可以跑 BSGS。
回到 $a^{30}a^{im-j}=b$
首先提取公因数 $g=(a^{30},p)$ 使得 $a$ 和剩余的模数互素，从而转化为普通的 BSGS 问题，即：
$\frac {a^{30}}{g}a^{im-j}=\frac{b}{g} \pmod {\frac{p}{g}}$。
这里可以判定 $(a^{30},p)|b$，如果不满足直接无解。
设 $p'=\frac{p}{g}$，$b'=\frac{b}{g}$，则上式可整理为：
$\frac {a^{30}}{g}a^{im-j}=b' \pmod {p'}$。
$\frac {a^{30}}{g}a^{im}=b'a^j \pmod {p'}$。
因为同余模数变为了 $p'$，同余方程可选用 $a'=a\%p'$ 代替 $a$。
注意，在求 $a^{30}$ 的时候可以取模，因为与 $p$ 公因数 $g$ 不会被 $p$ 模掉。这里跑 $30$ 次幂可以确保 $p$ 中所有不超过 $30$ 次的素因数的幂最后都会被累积到 $g$ 里面，适用在 $p \le 2^{30}$ 范围的数据。

```cpp
ll exbsgs(ll a, ll p, ll b) {
    ll v = 1 % p;
    a %= p, b %= p;
    for (int i = 0; i < 30; i++) {
        if (v == b % p) return i;
        v = v * a % p;
    }
    ll g = gcd(v, p);
    if (b % g) return -1;
    b /= g, p /= g, a %= p;
    map<int, int> mp;
    int B = ceil(sqrt(p)), ans = p;
    ll bk = qp(a, B, p), pd = v / g;
    for (int i = 1; i <= B; i++) {
        pd = pd * bk % p;
        if (!mp.count(pd)) mp[pd] = i * B;
    }
    pd = b;
    for (int i = 1; i <= B; i++) {
        pd = pd * a % p;
        if (mp.count(pd)) ans = min(ans, mp[pd] - i);
    }
    if (ans == p) return -1;
    return ans + 30;
}
```

## 固定模数批量处理
给定一个素数 $p$ 及其原根 $g$，给定若干 $y$，求 $x=\log_g y \pmod p$。
在前面的单个处理中，令 $m=\lceil \sqrt{p} \rceil$，方程的解 $x=im-j$，如果预处理 $g^m,g^{2m},g^{3m},...g^{m^2}$ 并记录结果，之后枚举 $g,g^2,g^3,...g^m$，则一定可以匹配到一个 $g^{im}g^{-j}=g^x$。
$g^{im}g^{-j}=y$ 即 $g^{im}=yg^j$。预处理复杂度 $O(\sqrt{p})$，查询操作 $O(\sqrt{p})$，总复杂度 $O(\sqrt{p})$。

如果现在需要求解的离散对数为 $q$个，按上面的做法，预处理还是 $O(\sqrt{p})$，查询复杂度 $O(q\sqrt{p})$，后者将主导总复杂度。因此需要加大预处理的范围。
设后续单个输入的查询量为 $B$，总查询量为 $qB$。为了实现 $O(B)$ 查询，预处理的间距需要为 $B$，预处理量为 $O(\frac{p}{B})$。总复杂度为 $O(\frac{p}{B}+qB)$，当 $B=\sqrt{\frac{p}{q}}$ 时，取到最小 $O(\sqrt{pq})$。空间复杂度同样为 $O(\sqrt{pq})$。
对于很大的 $p$ 和 $q$ 仍然不太够。

实际上，要进一步降低复杂度，需要用到一些对数的性质。
令 $\lfloor \frac{p}{y} \rfloor=m$，$p-my=r$。
即 $y=\frac{p-r}{m}$。
$\log_g y=\log_g(p-r)-\log_g m$
$\log_g y=\log_g(-r)-\log_g m$
$\log_g y=\log_g(-1\times r)-\log_g m$
$\log_g y=\log_g(p-1) + \log_g r-\log_g m$
注意，由于 $g$ 是原根，$g^{\frac{p-1}{2}}=-1$，即 $p-1$ 对应的指数为 $\frac{p-1}{2}$。
所以 $\log_g y=\frac{p-1}{2} + \log_g r-\log_g m$
这里有两个未知量，一个是 $r$，一个是 $m$。
$r$ 是 $p$ 除以 $y$ 的余数，$m$ 是 $p$ 除以 $y$ 的商。
如果我们预处理 $\sqrt{p}$ 以内的离散对数，则若 $y\le \sqrt{p}$ 可直接知道 $\log_g y$ 的结果，而若 $y \gt \sqrt{p}$，则 $m \le \sqrt{p}$，可直接知道结果。因而只有 $r$ 需要递归计算。

对 $p-my=r$ 稍加变形 $p-(m+1)y=r-y$
移项目，去掉 $p$，得 $(m+1)y=y-r$
取对数 $\log_g (m+1)y=\log_g (y-r)$
$\log_g (m+1) + \log_g y=\log_g (y-r)$
$\log_g y=\log_g (y-r) - \log_g (m+1)$
由此得到了另一种计算 $\log_g y$ 的方式。
与前面一样，预处理完 $\sqrt{p}$ 内的离散对数后，如果 $y \le \sqrt{p}$ 则直接知道了结果，需要处理的只是 $y \gt \sqrt{p}$ 部分的结果，此时 $m+1 \le \lceil \sqrt{p} \rceil$。综上只需要预处理 $\lceil \sqrt{p} \rceil$ 范围内的离散对数，$m$ 的部分都能 $O(1)$ 得到。
关键还是 $r$，在第二种表达式中，我们需要计算的是 $\log_g(y-r)$，第一种表达式中需要计算的是 $\log_g r$。对比一下可以知道 $min(r,y-r) \le \frac{y}{2}$。所以我们可以选取更小的一个进行递归，递归深度 $O(\log y)$。
因此，考虑 $y$ 在 $p$ 以内，查询复杂度为 $O(qlogp)$。

但是达到此复杂度的前提是预处理 $\sqrt{p}$ 范围内的离散对数，直接用 BSGS 暴力做，单个点是 $O(\sqrt{p})$ 的，因此总计是 $O(p)$ 的。
注意对数的性质，如果 $z=xy$，则 $\log_g z=log_g xy=log_g x + \log_g y$，也就是说从小到大处理时，所有的合数离散对数都能直接 $O(1)$ 得到，关键是需要硬求素数离散对数。在 $\sqrt{p}$ 范围内有 $\frac{\sqrt{p}}{\log \sqrt{p}}$ 个素数，每个素数用 BSGS 求离散对数复杂度为 $O(\sqrt{p})$，复杂度为 $\frac{p}{\log \sqrt{p}}$。
但是这个复杂度并不优，回看我们此部分的前面的分析，分块为 $\sqrt{p}$ 最优仅在查询轮数为 $1$ 时，此时预处理复杂度 $O(\sqrt{p})$，查询 $O(\sqrt{p})$。但如我们需要计算 $\frac{\sqrt{p}}{\log \sqrt{p}}$ 个数的离散对数，即需要查询 $\frac{\sqrt{p}}{\log \sqrt{p}}$ 轮，会造成预处理复杂度相对低，查询复杂度过高，因此需要调小分块，预处理更多数据，提升查询速度。
设分块大小为 $B$，预处理复杂度为 $O(\frac{p}{B})$。
查询时，单次复杂度为 $B$，总复杂度为 $B\frac{\sqrt{p}}{\log \sqrt{p}}$。
总复杂度为 $O(\frac{p}{B}+B\frac{\sqrt{p}}{\log \sqrt{p}})$，当 $B^2=\sqrt{p}\log \sqrt{p}$，即 $B=\sqrt{\sqrt{p}\log \sqrt{p}}=p^{0.25} \sqrt{\log \sqrt{p}}$ 时，复杂度达到最低 $O(\frac{p^{0.75}}{\sqrt{\log \sqrt{p}}})=O(\frac{p^{0.75}}{\sqrt{\log p}})$。
空间需求只需要保存 $\sqrt{p}$ 以内的离散对数，以及 $O(\frac{p}{B})=O(\frac{p^{0.75}}{\sqrt{\log p}})$ 保存预处理的离散对数，总空间复杂度 $O(\frac{p^{0.75}}{\sqrt{\log p}})$。

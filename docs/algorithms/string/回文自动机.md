# 回文自动机

回文自动机类似于 AC 自动机，在 AC 自动机中，从根到结点的路径对应了一个字符串，而回文自动机中从根到结点的路径对应了一个回文串。
回文自动机可以求出每个点作为终点的最大回文长度，进而得到回文总数以及本质不同回文总数。

不过回文自动机基于回文树，树上每个结点代表一种回文。一个指针 $p$ 记录处理完每个位置后，以该位置作为结尾的最长回文对应的结点。

假定此时新加入一个字符 $s_i$，由于 $i$ 前面的 $len_p$ 个字符构成回文，如果 $s_i=s_{i-len_p-1}$，则原回文套上两端后构成一个 $len_p+2$ 的回文。
如果 $s_i \ne s_{i-len_p-1}$，则不能直接组合成回文。类比 kmp，需要跳 $fail$，保证在后缀始终是回文的前提下，找到一个结点 $q$，使得 $s_i=s_{i-len_q-1}$，才能求到以 $s_i$ 作为结束的最长回文。这一过程实际上是在不断缩短回文后缀，只不过 kmp 是确保前后缀子串匹配，在此基础上都向后延展，而回文自动机是保证后缀串自身是回文的情况下，分别向前后延展。
其实可以发现，关键都是要求出 fail 数组，即保证跳跃后仍然是回文的后缀。

但无论如何，就像 AC 自动机，需要先造出结点才能在结点间连 $fail$。作为基础，可以先写出 getpos 函数，找到新的字符对应的最长回文长什么样子，即对应在树上哪里。可以以目前 $p$ 对应的回文为基础，不断尝试找到一个回文后缀，使得新后缀加上左右两端的单个字符构成回文。
```cpp
int getpos(int p, int now) {
    while (s[now - len[p] - 1] != s[now]) p = fail[p];
    return p;
}
```
当找到这样一个结点 $p$（及对应的长度）后（一定会找到，极端形况下会退化为空串），如果 $p$ 结点不存在 $s_i$ 分支结点，则新建结点。
接下来考虑如何对新结点计算 $fail$ 值，即当此回文无法延拓给定的字符时，其最长后缀回文是什么。
维护方式与 AC 自动机类似，让 $p$ 向前跳，对应的回文不断缩短（保持后缀重叠），直到找到一个 $q$，使得 $S_i=S_{i-len_q-1}$。注意，每个 $p$ 指向的结点都对应一个回文串。
此时，就得到新回文 $p$ 在失败后对应的后缀回文 $q$，即 $fail_p=q$
形象地说，就是如果当前回文串是 $c...c$，需要从 $...$ 中找一段回文后缀，之后看这段后缀左边是否也是 $c$，如果是，就找到了一个 $c...c$ 的回文后缀。
```cpp
fail[++tot] = nxt[getpos(fail[last], id)][c];
```

可以用 $dep$ 数组记录每个结点可以跳回文的次数，得到每个位置作为结束的回文个数。
将 $p$ 移动到 $s_i$ 分支，表示以 $i$ 为结束的最长回文。
```cpp
void add(int id) {
    last = getpos(last, id);
    int c = s[id] - 'a';
    if (!nxt[last][c]) {
        fail[++tot] = nxt[getpos(fail[last], id)][c];
        nxt[last][c] = tot;
        len[tot] = len[last] + 2;
        dep[tot] = dep[fail[tot]] + 1;
    }
    last = nxt[last][c];
    cnt[last]++;
}
```

与 kmp 类似，对 $p$ 进行 getpos 最多前移的次数就是字符串长度，因为只有 $p$ 对应的长度增加之后才能减少。
对 $fail_p$ 进行 getpos 的复杂度也是字符串长度。这是因为只有新建结点的时候才会调用 $getpos(fail_p)$，而新建点如果与前面的一段构成回文，则其前一个位置作为结束也必然有一个回文（即砍掉两端），也就是说要从其前序点的 $fail$ 继续向前跳，总跳次数也不会超过字符串长度。这其实相当于除了维护 $p$ 之外，还维护了一个更短小后缀版的 $p$。

为方便起见，可以建两个特殊点，一个长度为 $0$，用于延展 $aa$ 这种偶串，一个长度为 $-1$，用于延展 $a$ 这种奇数串。并且前者失败后指向后者。
```cpp
fail[0] = tot = 1, len[1] = -1, s[0] = '^';
```

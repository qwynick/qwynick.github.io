可持久字典树
$nxt$ 就是字典树，$cnt$ 记录单词数量，$root$ 记录版本
```cpp
int nxt[M][2], cnt[M], root[N], tot;
void init(int n) {
    for (int i = 0; i <= n; i++) root[i] = ++tot;
}
```

首先跟其他可持久一样，把 $!c$ 的指针拷贝过去。
对于 $c$ 方向新建一个节点（持久化，而非直接改老版本）。
新旧版本都移动到 $c$ 点，继续处理。
```cpp
void ins(int x, int node0, int node) {
    node0 = root[node0], node = root[node];
    for (int j = 29; j >= 0; j--) {
        int c = x >> j & 1;
        if (node0) nxt[node][!c] = nxt[node0][!c];
        nxt[node][c] = ++tot;
        node = nxt[node][c], node0 = nxt[node0][c];  // not exist will went to deadly 0
        cnt[node] = cnt[node0] + 1;
    }
}
```

跟可持久化线段树一样，卡出一个版本区间，差值为版本间存在的数据。
本题是查最大值，尽量优先走反向。
```cpp
int query(int x, int node0, int node) {
    int res = 0;
    node0 = root[node0], node = root[node];
    for (int j = 29; j >= 0; j--) {
        int c = x >> j & 1;
        if (cnt[nxt[node][!c]] > cnt[nxt[node0][!c]])
            node = nxt[node][!c], node0 = nxt[node0][!c], res |= 1 << j;
        else
            node = nxt[node][c], node0 = nxt[node0][c];
    }
    return res;
}
```

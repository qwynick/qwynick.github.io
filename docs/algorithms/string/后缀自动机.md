---
title: "后缀自动机"
catagory: string
---

后缀自动可以以 $O(n)$ 时间和空间记录所有子串。最终的效果是任何子串都可以从起点开始沿着正向边移动得到，且路径唯一。

基本思想可以理解为从起点开始做了一条主链，链上各个节点就是各个字符，主链长度就是原字符串长度。
但是这样的话，显然只包含了起点开始的各个子串。从中间开始的子串需要通过额外建点和边来囊括进去。

为方便起见，下述结点所代表的子串等价于以该结点作为结束点的路径对应的字符串；下述结点所代表（表示）的子串长度一律表示以该结点所代表的**最长**子串长度。某结点的后缀结点表示除某结点本身外，所有后缀子串所在的结点。最长后缀结点是指所有后缀结点中，表示的后缀串最长的那个结点。

很显然的是，当路径变成网状之后，到达同一个结点可以有多条路径，因此以同一个结点作为结束可以代表多个字符串。后缀自动机构建过程保证以同一个结点作为结束的子串，具有后缀包含关系。
且具体表示的后缀长度可由自身长度以及自动机中他的最长公共后缀状态的长度共同确定。
假设现在已经有一个能表示字符串 $s$ 的后缀自动机，如果多加一个 $c$ 字符在后面，很显然，可以在主链上延长一格。
新加入 $c$ 后，会产生若干个以 $c$ 结尾的子串，那么怎么把这些路径添加进去呢？

我们给起点（空串）编号为 $1$，并用 $fa_i$ 指向 $i$ 结点所表示的子串在自动机中的最长子串结点，即最长后缀结点。（这个之前已经进入自动机的结点已经代表了比该结点更短串的信息，新串只需要记录长度超过这个结点的信息）
关于 $fa$ 数组，举个例子，比如：有一个节点 $x$ 可以作为 $g,fg$ 的结尾，有一个节点 $y$ 可以作为 $efg,defg,cdefg$ 的结尾，有一个节点 $z$ 可以作为 $bcdefg,abcdefg$ 的结尾。那么 $fa_z=y,fa_y=x$。就是指向最长后缀结点。

考虑原串是 $aabab$ 现在新加入一个 $c$，由于新的子串包括 $aababc,ababc,babc,abc,bc,c$ 所以需要从所有这些不含最后的 $c$ 的子串所在的结点，连一条边到最后这个结点。
当然，由于一个结点可能代表多个子串，因此并不一定需要连 $6$ 条边。
为了确定需要由哪些结点向这个最新的结点连边，需要知道 $aabab$ 的所有后缀结点，这个可以通过跳 $fa$ 实现，因为 $fa$ 就是保存的最长后缀结点。
在处理 $c$ 的边时，显然 $aabab$ 的跳转关系已经求完了，上述任务是可以完成的。
具体操作为，让 $p$ 指向主链之前的最后一个结点，$now$ 表示主链新的最后一个结点，只要 $p$ 不指向虚空结点，且 $p$ 结点没延伸过 $c$，就不断让 $nxt_{p,c}=now,p=fa[p]$，即让全部后缀结点指向 $c$，形成新的子串。
如果某一时刻 $nxt_{p,c}$ 有结点，说明某个较短的后缀接 $c$ 已经在自动机中存在，那么更短的显然也存在，就没必要改造下去了；如果 $p$ 跑到了虚空结点，即在起点处（$1$ 号结点）也没停下来，说明 $c$ 从没出现过，现在跑出自动机了，自然也得停止。

现在考虑处理 $c$ 结点的 $fa$ 指向。
此时如果 $p$ 跑出了自动机，说明到 $c$ 为止的整串无任何后缀结点，即 $c$ 从没出现过（否则至少应该在起点处发现单 $c$ 这条分支），因此 $fa_{now}=1$ 表示最长后缀为空，也就是用最后这个结点代表了所有 $c$ 结尾的子串。
如果 $p$ 不为空，说明子串在自动机中存在。令 $q=nxt_{p,c}$，如果 $len_p+1=len_q$，说明 $q$ 结点仅代表一个子串，此时全串的最长后缀结点就是 $q$。
如果 $len_p+1<len_q$，那么说明 $q$ 结点代表了多个子串，除了其中一个是仅添加 $c$ 以外，还有更长的，这些都不是原串的后缀子串（相当于在 $spt$ 处发生劈叉），不能直接指定 $fa$。
为了解决这个问题，可以从 $p$ 开出一个分支 $spt$，把长度为 $len_p+1$ 的后缀串独立出来，该结点仅代指这一个长度 $len_p+1$ 的子串，其为 $q$ 所代表的后缀子串中的一部分，是比 $fa_q$ 长但比其余 $q$ 短的一部分后缀子串。考虑后缀包含关系，应该设置 $fa_{spt}=fa_q,fa_q=fa_{now}=spt$。由于 $spt$ 代表的串原先是被 $q$ 所代表的，和 $q$ 就是同一个点，即便为了给最后结点连 $fa$ 而分离出来，向后的转移还是不变的，所以复制 $nxt_{spt,i}=nxt_{q,i}$。
最后，由于 $q$ 中较短的一部分串 $spt$ 被分离出来，所以原先 $p$ 的后缀结点中走 $c$ 到 $q$ 的情况要修改为到 $spt$。

上述分裂过程非常抽象，用一个简单的例子来演示，依次插入 $aabb$。
插入 $a$，$root\rightarrow a$；$fa_2=1$ 没有出现过 $a$，会跳出自动机。
插入 $a$，$root\rightarrow a \rightarrow a$；$fa_2=1,fa_3=2$ 跳一次到起点就发现了存在 $a$，长度也合适，直接接上去。实际上 $len_p+1$ 以内的后缀串正好被 $fa_3=2$ 这个点表示了。
插入 $b$，$root\rightarrow a \rightarrow a \rightarrow b$；$fa_2=1,fa_3=2,fa_4=1$ 没有出现过 $b$，会跳出自动机。
此时，第一个 $a$ 结点代表 $a$，此二个 $a$ 结点代表 $aa$，第三个 $b$ 结点代表 $aab,ab,b$。
插入 $b$，$root\rightarrow a \rightarrow a \rightarrow b \rightarrow b$。
第四个需要代表 $aabb,abb,bb$（开天眼了，其实运算前并不知道）。即，我们需要找到一个结点，他的长度正好是 $1$，这样续上去就正好省掉了 $b$。
我们从 $aab$ 开始往前跳，直到可以接 $b$，此时就得到 $aabb$ 在自动机中的最长后缀结点。
在这个具体的例子中，会找到起点，因为在第三轮中，起点曾经接过 $b$。
但是由于起点的 $len_p+1=len_1+1=1$，而第一个 $b$ 字符的 $len_q=len_4=3$，不匹配。本来预期是接到一个长度为 $len_p+1=1$ 的仅包含 $b$ 的结点上，结果接到了包含 $aab,ab,b$ 的结点上，$b$ 只是其中较短的部分。如果硬接过来，逻辑上 $aab,ab$ 都不是 $aabb$ 的后缀；而在自动机上由于最后节点的 $fa$ 结点的长度只比最后结点小 $1$，实际效果是忽略了 $bb,abb$ 这两个后缀。所以不能直接指向 $q$ 上，而如果继续跳跳出了自动机，从而指向起点，又会有两个结点都记录了 $b$，造成重复。
一个修正的方式是单开一个结点保存这个特定长度的后缀。让这个新开的点（即 $spt$）的 $fa$ 指向原来第三个点（即 $q$）的 $fa$，然后第三个点和第四个点（即 $now$）的 $fa$ 都指向这个新开的点。这样既保证了最后这个点的所有子串都记录在案，同时 $b$ 及更短的子串也都只在一个结点（$spt$ 或其各级 $fa$）被记录。
由于 $spt$ 原来归属于 $q$ 结点，分裂后他的后续连边情况应该从 $q$ 照抄过来。
同时，如果 $p$ 的后缀子串接 $c$ 后归属 $q$，则此时应该去 $spt$ 结点。

```cpp
void add(int c) {
    int p = last, now = ++tot;
    last = now;
    len[now] = len[p] + 1;
    cnt[now] = 1;
    for (; p && !nxt[p][c]; p = fa[p]) nxt[p][c] = now;
    if (!p) {
        fa[now] = 1;
        return;
    }
    int q = nxt[p][c];
    if (len[p] + 1 == len[q]) {
        fa[now] = q;
        return;
    }
    int spt = ++tot;
    len[spt] = len[p] + 1;
    copy(nxt[q], nxt[q] + C, nxt[spt]);
    fa[spt] = fa[q], fa[q] = fa[now] = spt;
    for (; p && nxt[p][c] == q; p = fa[p]) nxt[p][c] = spt;
}
```

每个新加字符，最多只会建两个结点，所以空间是 $O(n|\Sigma|)$。
转移数是 $O(n)$ 的，所以第一个循环总时间复杂度也是 $O(n)$ 的。
新建节点是 $O(n)$ 个，每个分裂节点可能需要复制 $O(n|\Sigma|)$ 的数据，时间复杂度也是 $O(n|\Sigma|)$ 的。
最后个循环比较麻烦，但是也可以证明是 $O(n)$ 的。

# Manacher

首先把原字符串塞入 `#` 进行分割，这样奇偶都能同样处理。
奇串中心是原字符，偶串中心为 `#`。
变量 $M$ 记录最远回文对应的回文中心，$R$ 记录最远回文对应的右端点。
当考虑一个新位置 $i$ 作为中心的最长回文长度时有几种可能：
①点 $i$ 在 $R$ 以内，其相对于 $M$ 有一个对称点在之前已经处理过，由于 $M$ 点为中心是回文，所以 $i$ 的回文情况与对称点 $2M-i$ 是一样的。如果 $i+len[2M-i]<R$，那么 $i$ 点为中心得回文不会超过 $R$，结果已经确定。
②点 $i$ 在 $R$ 以内，但是 $i$ 到 $R$ 的距离小于等于对应点的回文半径 $len[2M-i]$，则 $i\sim R$ 这一段是 $i$ 为中心的回文的右半部分，$R$ 之外的需要暴力判断。
③点 $i$ 超出 $R$ 了，直接暴力判断即可。
上述②③可以合并处理。

每个位置算完后，如果回文涉及的最大位置超过原先的 $R$，设置新的 $M$ 和 $R$。
复杂度在于暴力比较，而暴力比较的次数为字符串长度量级。
```cpp
s[0] = '^';
for (int i = 0; t[i]; i++) s[++n] = '#', s[++n] = t[i];
s[++n] = '#', s[++n] = '$';
int M = 0, R = 1;
for (int i = 1; i < n; i++) {
    if (i < R && i + len[2 * M - i] < R) {
        len[i] = len[2 * M - i];
    } else {
        int k = R + 1 - i;
        while (s[i - k] == s[i + k]) k++;
        len[i] = k - 1;
        M = i, R = i + len[i];
    }
}
```

# 扩展KMP

$z_i$ 记录了从第 $i$ 位置开始，与原串的最长公共前缀。
$L$ 记录最远前缀匹配的起点，$R$ 记录最远前缀匹配的终点。
如果当前位置在 $R$ 之内，那么 $i$ 开始的匹配情况，等于 $i-L+1$ 开始的匹配情况。这是因为 $1$ 对应 $L$，$2$ 对应 $L+1$ ... $i-L+1$ 对应 $i$。
当然，如果字符串以 $0$ 作为起点，那么对应的是 $i-L$。
如果该处的匹配长度 $z_{i-L+1}+i$ 不超出 $R$，那么就是结果；如果超过了，由于 $R$ 开外的匹配信息并没处理过，那么 $z_{i-L+1}$ 不能完全使用，只能匹配到 $R$。
如果通过前述信息匹配到 $R$，对于 $R$ 开外的直接暴力匹配即可。
暴力匹配后 $R$ 会增加，增加次数不超过字符串长度，所以保证了复杂度。

每次匹配完后，如果前缀涉及的位置超出了 $R$，修改对应的 $L$ 和 $R$。
```cpp
int exkmp(char *s, int n, char *t, int m) {
    t[m] = '#';
    copy(s, s + n, t + m + 1);
    z[0] = m;
    int L = 0, R = -1, ret = 0;
    for (int i = 1; i <= n + m; i++) {
        if (i <= R)
            z[i] = min(z[i - L], R - i + 1);
        else
            z[i] = 0;
        while (i + z[i] <= n + m && t[i + z[i]] == t[z[i]]) ++z[i];
        if (i + z[i] - 1 > R) L = i, R = i + z[i] - 1;
        if (z[i] == m) ret++;
    }
    return ret;
}
```

---
title: "后缀数组"
catagory: string
---


$c$ 数组用于计数，$sa_i$ 保存第 $i$ 小串的起点位置，$rk_i$ 保存 $i$ 位置所属的桶，$h_i$ 保存 $i$ 位置的后缀串与排名比他小 $1$ 小的后缀串的 $LCP$。
```cpp
int c[N], sa[N], rks[2][N], h[N], *tmp, *rk;
void build(int n, int m = 128) {
    fill(c, c + m + 1, 0), rk = rks[1], tmp = rks[0]; // tmp在swap前记录的是：第二关键字第i小的串的起点。
    for (int i = 1; i <= n; i++) c[rk[i] = s[i]]++; // 第一轮先按单个字母作为键值，记录第i位置所属的桶，把数量计到c。
    for (int i = 1; i <= m; i++) c[i] += c[i - 1]; // 前缀和，准备基数排序
    for (int i = n; i >= 1; i--) sa[c[rk[i]]--] = i; // 从后向前处理起点，查出各个桶最后一个数的排名，用完后给桶最后编号-1，并记录这一排名的串起点在i。
    for (int l = 1; l < n; l *= 2) { // 倍增字符串长度，第一轮从1变2，第二轮从2变4。
        int ct = 0;
        for (int i = n - l + 1; i <= n; i++) tmp[++ct] = i; // 对于+l越界的部分，他们的第二关键字都是0，所以他们的第二关键字占据最小的若干个rank。
        for (int i = 1; i <= n; i++)
            if (sa[i] > l) tmp[++ct] = sa[i] - l; // 对于+l不越界的部分，该部分的第二关键字实际上在pos+l，按升序取出起点sa[i]后，该串对应为sa[i]-l这一起点的第二关键字。因为第一关键字从小到大取的，对应第二关键字也是从小到大的，所以sa[++ct]~sa[++i]，只不过原来sa[i]作为起点的第一关键字，对应sa[i]-l处的第二关键字，所以该段后缀记录的位置是在sa[i]-l。注意，第二关键字的起点sa[i]必须大于l。
        fill(c, c + m + 1, 0);
        for (int i = 1; i <= n; i++) c[rk[i]]++; // 将前一轮排出的rank进行计数
        for (int i = 1; i <= m; i++) c[i] += c[i - 1]; // 前缀和，准备基数排序
        for (int i = n; i >= 1; i--) sa[c[rk[tmp[i]]]--] = tmp[i]; // 按第二关键字倒序取出后缀，抓取该后缀所属的桶，计数-1。（保证了对于同样的第一关键字，优先把第二关键字大的先放到后面）
        swap(rk, tmp), m = 0; // 交换后，tmp放的是各个位置的后缀的排名
        for (int i = 1; i <= n; i++)
            if (tmp[sa[i]] == tmp[sa[i - 1]] && tmp[sa[i] + l] == tmp[sa[i - 1] + l]) // 如果前半段和后半段都相等，排名不变
                rk[sa[i]] = m;
            else // 否则排名增加1
                rk[sa[i]] = ++m;
        if (m == n) break; // 完全区分开了n个起点
    }
    for (int i = 1, k = 0; i <= n; i++) {
        if (k) k--; // 只要前一位置的LCP不为0，先预减1。因为比如前面一个位置比完了abcd和abce，此时用bcd去比，至少有个bce，也就是掐掉了1个字母a，最差也就是-1。
        if (rk[i] == 1) continue; // 第一个和前面没有LCP
        int j = sa[rk[i] - 1]; // j位置是比第i位置后缀小一名的位置
        while (s[i + k] == s[j + k]) k++;  // 只要相等就一直加。k的值就是第i大
        h[rk[i]] = k; // 记录i位置的后缀序列与在他前面一个rank的后缀序列的LCP=k
    }
}
```

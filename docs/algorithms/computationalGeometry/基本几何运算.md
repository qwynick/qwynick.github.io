最常用的矢量运算：叉积和点积：
```cpp
T cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
T dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
```
叉积的定量结果为 $a \times b=|a||b|sin\theta$，其中 $\theta$ 为夹角。结果就是两条矢量张开的平行四边形的面积。另一方面如果矢量 $a$ 经逆时针旋转小于 $\pi$ 转到 $b$，则结果为正，常用于判定矢量的方向关系。
点积的定量结果为 $a \cdot b=|a||b|cos\theta$，其中 $\theta$ 为夹角。如果某一个矢量是单位矢量，其结果等于另一矢量在单位矢量方向上的投影长度。运用点积，也可以很方便地求出两条线段的夹角 $cos\theta=\frac{a\cdot b}{|a||b|}$。这里叉积不方便，因为正弦无法分辨是 $\theta$ 还是 $\pi-\theta$。

为了方便比较浮点数大小，需要重写比较函数，误差在界限内的即认为相等。其逻辑非常直接。
```cpp
int sgn(T a) {
    if (fabs(a) < eps) return 0;
    return a > 0 ? 1 : -1;
}
int cmp(T a, T b) {
    if (fabs(a - b) < eps) return 0;
    return a > b ? 1 : -1;
}
```

求线段长度，长度的平方，两点距离。
```cpp
T length(Point a) { return sqrt(dot(a, a)); }
T length2(Point a) { return dot(a, a); }
T dis(Point a, Point b) { return length(a - b); }
```

运用余弦求角度，不再赘述。
```cpp
T angle(Point a, Point b) { return acos(dot(a, b) / (length(a) * length(b))); }
```

一般都把多边形剖分为多个三角形，再求面积，因此三角形面积比较重要。这里如果三个点是逆时针，面积为正，反之为负。
```cpp
T area2(Point a, Point b, Point c) { return cross(b - a, c - a); }
T area(Point a, Point b, Point c) { return area2(a, b, c) / 2; }
```
矢量逆时针旋转 $\theta$。
```cpp
Point rotate(Point a, T theta) { return {a.x * cos(theta) - a.y * sin(theta), a.x * sin(theta) + a.y * cos(theta)}; }
```

以上都是基本工具函数，以下的比较复杂一些。
```cpp
Point intersect(Point a, Vector va, Point b, Vector vb) {
    Vector u = b - a;
    T k = cross(u, va) / cross(va, vb);
    return b + vb * k;
}
```

已知两条直线（以点向式表示），求交点。
```cpp
Point intersect(Point a, Vector va, Point b, Vector vb) {
    Vector u = b - a;
    T k = cross(u, va) / cross(va, vb);
    return b + vb * k;
}
```
考虑 $va,vb$ 不平行的情况，$u,va,vb$ 三个矢量代表的直线构成的三角形。取 $u$ 为定值，通过适度伸缩 $v_a,v_b$ 至 $v_a',v_b'$，可以构成三角形，而伸缩后 $v_a'=k_av_a,v_b'=k_bv_b$ 的交点即为两条直线的交点。
此时由三角形面积公式 $u \times v_a' = v_a' \times v_b'$。带入倍数关系，即
$u \times k_av_a = k_av_a \times k_bv_b$
$k_b = \frac{u \times v_a}{v_a \times v_b}$

如果是线段的交点，由于线段长度有限，需要先判断是否在线段范围内有交点。
判断方式比较直接，直接通过叉积看是否相互跨越。
```cpp
bool seg_intersect(Point a, Point b, Point c, Point d) {
    Vector ab = b - a, cd = d - c;
    return sgn(cross(c - a, ab) * cross(ab, d - a)) >= 0 && sgn(cross(a - c, cd) * cross(cd, b - c)) >= 0;
}
```
如果 $ab$ 和 $cd$ 有交点：则 $ac$ 和 $ad$ 应该位于 $ab$ 两边；且 $ca$ 和 $cb$ 应该位于 $cd$ 两边。只要相互跨越，一定是有交点的。

求一个点 $p$ 到直线 $ab$ 的距离，可以根据三角形面积等于底乘以高来计算。
求一个点 $p$ 到线段 $ab$ 的距离，需要判断垂足是否在线段上，可以用矢量的夹角来判断。
判断点 $p$ 在线段 $ab$ 上，首先判断在直线 $ab$ 上，在判断在线段内部。
```cpp
T line_dis(Point p, Point a, Point b) { return abs(area2(a, b, p) / length(a - b)); }
T seg_dis(Point p, Point a, Point b) {
    Vector ab = b - a;
    if (sgn(dot(ab, p - a)) < 0) return length(p - a);
    if (sgn(dot(ab, p - b)) > 0) return length(p - b);
    return line_dis(p, a, b);
}
bool on_seg(Point p, Point a, Point b) { return sgn(cross(p - a, p - b)) == 0 && sgn(dot(p - a, p - b)) <= 0; }
```
如果垂足在线段上，应当满足 $ap$ 与 $ab$ 夹角小于 $\pi /2$，同时 $bp$ 与 $ba$ 夹角小于 $\pi /2$。
如果其中一个不满足，说明垂足在那个点的外侧，那么那个点就是最近点。
如果 $p$ 在 $ab$ 直线上，则 $pa \times pb=0$。如果在范围内，要求 $ap \cdot bp \le 0$。

求点 $p$ 在直线 $ab$ 上的投影，可以运用点积就是投影的关系。
```cpp
Point project(Point p, Point a, Point b) {
    Vector ab = b - a, ap = p - a;
    T k = dot(ap, ab) / dot(ab, ab);
    return a + ab * k;
}
```
$ap$ 在 $ab$ 上的投影长度为 $ap$ 点乘 $ab$ 的单位矢量 $\frac{v_{ap} \cdot v_{ab}}{|v_{ab}|}$。
$ap$ 投影到 $ab$ 上对应的矢量为上述长度乘以单位矢量，即 $\frac{v_{ap} \cdot v_{ab}}{|v_{ab}|} \frac{v_{ab}}{|v_{ab}|}=\frac{v_{ap} \cdot v_{ab}}{v_{ab} \cdot v_{ab}}v_{ab}$。
所以投影点的位置为 $ap$ 的起点 $a$ 加上 $ap$ 投影到 $ab$ 的矢量
$a+\frac{v_{ap} \cdot v_{ab}}{v_{ab} \cdot v_{ab}}v_{ab}$

多边形面积，本质上是单拧出第一个点，其余点每两个相邻点与第一个点连成三角形，把所有三角形面积加起来即得整体面积。这个公式对于凹多边形仍然成立。
```cpp
T area_poly(Point p[], int n) {
    T ret = 0;
    for (int i = 1; i < n - 1; i++) ret += cross(p[i] - p[0], p[i + 1] - p[0]);
    return fabs(ret) / 2;
}
T area_poly2(Point p[], int n) {
    T ret = 0;
    for (int i = 1; i < n - 1; i++) ret += cross(p[i] - p[0], p[i + 1] - p[i]);
    return fabs(ret);
}
```

已知三点 $a,b,c$ 求圆心，直接运用弦的中垂线过圆心，然后两个中垂线交点即是圆心即可。
```cpp
Point cirCenter(Point a, Point b, Point c) {
    Point ab = b - a, ac = c - a;
    T abl = length2(ab), acl = length2(ac), s = 2 * cross(ab, ac);
    return a - Point{ab.y * acl - ac.y * abl, ac.x * abl - ab.x * acl} / s;
}
```
实际操作并没有这么算，因为会涉及多条线段转化。
假设圆心为 $o$，则
$\left\{
\begin{aligned}
v_{oa}+v_{ab}=v_{ob}\\
v_{oa}+v_{ac}=v_{oc}
\end{aligned}
\right.$
平方之后：
$\left\{
\begin{aligned}
v_{oa}^2+v_{ab}^2+2v_{oa}\cdot v_{ab}=v_{ob}^2\\
v_{oa}^2+v_{ac}^2+2v_{oa}\cdot v_{ac}=v_{oc}^2
\end{aligned}
\right.$
由于圆心到三个点距离相等，消掉两侧半径的平方，故：
$\left\{
\begin{aligned}
v_{ab}^2=2v_{ao}\cdot v_{ab}\\
v_{ac}^2=2v_{ao}\cdot v_{ac}
\end{aligned}
\right.$
将右侧各个矢量的 $x,y$ 写开，进行点积运算：
$\left\{
\begin{aligned}
v_{ab}^2=2(v_{{oa}_x} v_{{ab}_x}+v_{{oa}_y} v_{{ab}_y})\\
v_{ac}^2=2(v_{{oa}_x} v_{{ac}_x}+v_{{oa}_y} v_{{ac}_y})
\end{aligned}
\right.$
上式中 $v_{ab},v_{ac}$ 的各个分量都是已知的，左侧也是已知的，所以可以求解出 $v_{oa}$。比如以 $v_{{oa}_y}$ 作为桥梁：
$\frac{v_{ab}^2/2-v_{{oa}_x} v_{{ab}_x}}{v_{{ab}_y}}=v_{{oa}_y}=\frac{v_{ac}^2/2-v_{{oa}_x} v_{{ac}_x}}{v_{{ac}_y}}$
$v_{ab}^2v_{{ac}_y}/2-v_{{oa}_x} v_{{ab}_x}v_{{ac}_y}=v_{ac}^2v_{{ab}_y}/2-v_{{oa}_x} v_{{ac}_x}v_{{ab}_y}$
移项提取 $v_{{oa}_x}$ 的系数：
$v_{ab}^2v_{{ac}_y}/2 - v_{ac}^2v_{{ab}_y}/2=v_{{oa}_x} (v_{{ab}_x}v_{{ac}_y}-v_{{ac}_x}v_{{ab}_y})$
令 $\Delta=2(v_{{ab}_x}v_{{ac}_y}-v_{{ac}_x}v_{{ab}_y})=2v_{ab}\times v_{ac}$
$v_{{oa}_x}=\frac{v_{ab}^2v_{{ac}_y} - v_{ac}^2v_{{ab}_y}}{\Delta}$
同理可得：
$v_{{oa}_y}=\frac{v_{ac}^2v_{{ab}_x} - v_{ab}^2v_{{ac}_x}}{\Delta}$

二维凸包是指给定平面上若干个点，求一个点最小凸多边形集囊括所有点。

有两种做法，一个是 Graham，一个是 Andrew。前者需要求极角排序，后者只需要普通排序。本文仅介绍 Andrew 算法。

Andrew 算法需要维护一个栈保存已知的凸包的点。假定逆时针构造凸包，首先按 $(x,y)$ 排序。
把最小的点作为凸包的第一个点压入栈。顺次考察各个点，因为是逆时针构造，前后线段应该呈现左拐的方向，因此凸包上各相邻线段的顺次叉积应该是正的。如果发现某各点的连线出现右拐，则说明之前一个点不需要，需要弹栈，否则出现凹陷。这样从左扫到右之后就求出了下半凸壳。
之后再倒着扫点求出上半凸壳，前后线段同样应当满足左拐。如果发现右拐则弹栈。注意最后一个点需要弹掉，因为他就是第一个点。回退的时候注意消除的不能是已经求好的下凸壳上的点。

```cpp
vector<Point> convexhull(Point d[], int n) {
    sort(d, d + n), n = unique(d, d + n) - d;
    vector<Point> ret(2 * n);
    int now = 0;
    for (int i = 0; i < n; ret[now++] = d[i++])
        while (now > 1 && cross(ret[now - 1] - ret[now - 2], d[i] - ret[now - 1]) <= 0) --now;
    for (int i = n - 2, t = now; i >= 0; ret[now++] = d[i--])
        while (now > t && cross(ret[now - 1] - ret[now - 2], d[i] - ret[now - 1]) <= 0) --now;
    if (ret.size() > 2) now--;
    ret.resize(now);
    return ret;
}
```
如果凸包没有退化为直线，第一个点会加两次，resize 是为了剔除他；但是退化为直线或者单点是不存在这个问题的（最后一轮把自己弹掉了）。
一开始的去重是为了防止开始阶段有重叠点，因为只有点数大于 $2$ 才会弹，这会导致两个重叠点。

## 闵可夫斯基和
如果两个点集求闵可夫斯基和后形成的新点集需要求凸包，可以对两个点集分别求凸包，然后把边按照极角序构成新的多边形。
几何理解：
点集A构成一个多边形，点集B构成一个多边形。
点集A和B之和构成的多边形的形态实际上可以理解为多边形A在多边形B的边上滑动构成的形状（共 $|A||B|$ 个顶点）。
最终的凸壳由两部分构成，一部分是A的顶点演B滑动的轨迹，一部分是A自身的边。如果不考虑平行的情况，一共会形成 $|A|+|B|$ 个点。
具体由谁构成，取决于A中边的方向以及当前滑动的B的边的方向。
在分别处理好AB的凸包后（假定从最左的点开始，逆时针加点），可以先对齐凸包第一个点，假设A中当前边为左下到向右上右上↗：
- 如果B中边的方向是水平向右→，那么滑动时A边的左下角会构成外围；
- 如果B中边的方向是竖直向上↑，那么滑动时A边的右上角会构成外围；
- 在B从水平向右→转到竖直向上↑的过程中，A这条斜边会构成外围。
以此类推，按照逆时针旋转方向将A和B的边逐个加入新多边形即可。
```cpp
vector<Point> mink(vector<Point>& L, vector<Point>& R) {
    int n = L.size(), m = R.size();
    auto l0 = L[0], r0 = R[0];
    vector<Point> ret{{L[0] + R[0]}};
    for (int i = 0; i + 1 < n; i++) L[i] = L[i + 1] - L[i];
    for (int i = 0; i + 1 < m; i++) R[i] = R[i + 1] - R[i];
    L.back() = l0 - L.back(), R.back() = r0 - R.back();
    ret.resize(L.size() + R.size() + 1);
    merge(L.begin(), L.end(), R.begin(), R.end(), ret.begin() + 1, [](Point a, Point b) { return cross(a, b) > 0; });
    for (int i = 1; i < ret.size(); i++) ret[i] = ret[i] + ret[i - 1];
    return ret;
}
```

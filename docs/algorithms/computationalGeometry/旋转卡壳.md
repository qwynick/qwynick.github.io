旋转卡壳，通过枚举凸包上一条边及对面一个顶点来刻画出一对夹住多边形的平行线。

对于凸包上的每条边，至多有两个凸包上的点到他的垂直距离最远，这个距离可以用三点构成的三角形面积来刻画。
随着边的旋转，对应的最远的顶点也会旋转，所以可以 $O(n)$ 求出所有边对应的最远点。最远点对一定在这些顶点与边的端点连线之中。

设凸包有 $n(n\ge 3)$ 个顶点，编号 $P_1,P_2,P_3,...,P_n$。
多边形至少需要有三个点，初始时枚举底边 $P_1P_2$，两个游标
$j=3,k=4$ 分别指向 $P_3,P_4$。这里 $j,k$ 是取模周期性旋转的。

只要 $S(P_1P_2P_j) < S(P_1P_2P_k)$ 就 $j,k$ 分别向后移一位。直到 $S(P_1P_2P_j) \ge S(P_1P_2P_k)$。
此时 $P_1P_2P_j$ 构成最大的面积，记录 $P_1P_j,P_2P_j$ 的长度。
之后底边转到 $P_2P_3$，再次判定如果 $S(P_1P_2P_j) < S(P_1P_2P_k)$，就 $j,k$ 分别向后移一位。
直到做完 $P_nP_1$，就得到了最长的距离，即直径。

```cpp
T rotatediameter(vector<Point> ch) {
    if (ch.size() <= 2) return length(ch[0] - ch.back());  // single line
    T ret = 0;
    int n = ch.size();
    ch.push_back(ch[0]);
    for (int i = 0, j = 2, k = (j + 1) % n; i < n; i++) {
        ret = max(ret, length(ch[j] - ch[i + 1]));
        ret = max(ret, length(ch[j] - ch[i]));
        while (area2(ch[i], ch[i + 1], ch[j]) < area2(ch[i], ch[i + 1], ch[k])) {
            j = k;
            k = (k + 1) % n;
            ret = max(ret, length(ch[j] - ch[i + 1]));
            ret = max(ret, length(ch[j] - ch[i]));
        }
    }
    return ret;
}
```

此外如果要找一个最小矩形覆盖，可以很容易想到，至少一条边会与多边形重合，否则可以稍加旋转形成分离，减小矩形面积。
所以用旋转卡壳枚举一对边，然后再用两个游标旋转另外一对边即可。

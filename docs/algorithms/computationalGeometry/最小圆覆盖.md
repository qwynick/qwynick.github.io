---
title: "最小圆覆盖"
catagory: computationalGeometry
---

最小原覆盖是给定若干个点，求一个最小的圆，能围住所有的点。
算法非常粗暴，就是通过三重循环找圆上的三个点。

基本思想就是增量维护一个圆，检查各个点在不在圆内，如果不在就从头开始把圆扩大。

初始化，圆心在 $P_1$，半径为 $0$。
之后第一重循环依次考察 $P_2,...P_n$：
- 如果 $P_i$ 在圆内，那么不用动圆。
- 如果 $P_i$ 不在圆内，那么如果一个最小的圆要覆盖 $P_1,P_2,...P_i$，这个最小圆必经过 $P_i$，将 $P_i$ 定为圆上一点。令圆心在 $P_i$，半径为 $0$，接下来对前面的点跑循环，确定第二个点：
  - 如果 $P_j$ 在圆内，那么不用动圆。
  - 如果 $P_j$ 不在圆内，那么 $P_j$ 应当在圆上，用 $P_iP_j$ 构造一个最小圆，显然两点构成直径。接下来对前面的的点跑循环，确定第三个点：
    - 如果 $P_k$ 在圆内，那么不用动圆。
    - 如果 $P_k$ 不在圆内，那么 $P_k$ 应该在圆上，此时用 $P_iP_jP_k$ 确定这个圆，继续验证剩余的小点。如果有点 $P_{k'}$ 落在了三点确定的圆之外，以 $P_iP_jP_{k'}$ 重新确定圆。跑完第三重循环，这样确定的圆一定是覆盖 $P_1...P_jP_i$ 的。
  - 继续跑剩下的第二重循环，如果无法覆盖 $P_{j'}$，则以 $P_iP_{j'}$ 为直径重新构造圆，跑完第三重循环确保覆盖 $P_1...P_{j'}P_i$。跑完剩下的第二重循环，得到的圆就覆盖了 $P_1...P_i$。
- 继续跑剩下的第一重循环，如果有一个点 $P_{i'}$ 不在圆内，则这个点一定在圆上，以他作为第一个点，重新跑第二、三重循环，确定第二、三个点。

由于最小圆覆盖是存在的，所以算法会找到结果。

```cpp
pair<Point, T> min_circle(int n) {
    Point o = d[0];
    T r = 0;
    for (int i = 1; i < n; i++) {
        if (dis(o, d[i]) < r + eps) continue;
        o = d[i], r = 0;
        for (int j = 0; j < i; j++) {
            if (dis(o, d[j]) < r + eps) continue;
            o = (d[i] + d[j]) / 2, r = dis(o, d[i]);
            for (int k = 0; k < j; k++) {
                if (dis(o, d[k]) < r + eps) continue;
                o = cirCenter(d[i], d[j], d[k]);
                r = dis(o, d[i]);
            }
        }
    }
    return {o, r};
}
```
注意三层循环的状态是以不一样的：
- 跑第一重循环的时候，手里是有一个覆盖了前 $i-1$ 个点的圆的，此时在验证这个圆是否对后面的 $i \le n$ 适用。如果没法覆盖，说明靠前 $i-1$ 个点确定的最小圆不行，需要将其增大到刚好覆盖 $P_i$。直接将 $P_i$ 作为第一个点，重新构造圆。
- 跑第二重循环的时候，手里是有一个覆盖了点 $i$ 及前 $j-1$ 个点的圆的，此时在验证这个圆是否对后面的 $j<i$ 适用。如果没法覆盖，说明这个点必须在圆上，将 $P_iP_j$ 设置为直径。
- 跑第三重循环的时候，手里是有一个覆盖了点 $i,j$ 及前 $k-1$ 个点的圆的，此时在验证这个圆是否对后面的 $k<j$ 适用。如果没法覆盖，直接把 $P_iP_jP_k$ 作为圆上三个点，跑完后第三重循环后一定能覆盖 $P_1...P_jP_i$ 以内的所有点，否则会矛盾。

关于第三重循环构造的圆必然覆盖前面的点，可以这样理解，首先 $P_1...P_jP_i$ 的最小圆覆盖一定存在，且 $P_i,P_j$ 任何一个不选为边界都无法构造出完全覆盖 $P_1...P_jP_i$ 的最小圆，说明他们都是在最小圆上的点。选对了点，最终一定能覆盖。自然，当把所有 $P_k$ 全跑一遍后，一定会遇上最后那个在边界上的点，一旦选中了他，就覆盖了全部。

第一重循环跑完后，就找到了一个能覆盖所有的点的圆。
设最终三个点编号为 $i_o,j_o,k_o$，第一重循环保证了 $i_o<pos \le n$ 的点被覆盖，第二重循环保证了 $j_o<pos<i$ 的点被覆盖，第三重循环保证了 $k_o<pos<j$ 的点被覆盖，圆的构造保证了 $1 \le pos<k_o$ 的点被覆盖。

最坏复杂度是 $O(n^3)$，平均复杂度是 $O(n)$。需要随机打乱数据避免出现极端情形。

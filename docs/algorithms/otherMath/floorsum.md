给出 $n,m,a,b$，求 $\sum_{i=0}^{n-1} \lfloor \frac{a \times i + b}{m} \rfloor$。

## $a \ge 0,b \ge 0$ 的情况。
若 $a \ge m$，可以先把整除部分拿出来，结果为 $\lfloor a/m \rfloor  \frac{n(n-1)}{2}$
若 $b \ge m$，可以先把整除部分拿出来，结果为 $\lfloor b/m \rfloor n$。
剩余部分为 $\sum_{i=0}^{n-1} \lfloor \frac{a \times i + b}{m} \rfloor$，这里的 $a,b$ 都是对 $m$ 取过模的，为方便起见，仍沿用取模前的变量名。
![图片](https://img2024.cnblogs.com/blog/3629076/202606/3629076-20260615220745336-105710922.png)
可以看到，上述求和式，本质上是对斜线下方（含）到 $y=0$（不含）之间的整数点进行数点。
很直观的结论是斜线向 $y=0$ 数点和向 $x=n$ 数点，结果应该是一样的（都不含终点那条线）。但是此时转为向 $x=n$ 数点会有一个好处。
注意到 $a<m$，所以如果把 $i$ 看成自变量，则直线方程斜率 $a/m$ 小于 $1$，
但是如果我们把坐标轴的 $x,y$ 互换，就会让斜率大于 $1$，进而又可以按前面的方法提出整数部分。
我们把图像顺时针旋转 $\pi/2$，此时 $x,y$ 轴已经互换，但是斜线的朝向变了，再按竖直轴对称一下，回到与一开始一样的朝向。
接下来的关键是交换坐标轴后，怎么求出等效的 $n,m,a,b$，使得在新图中，这几个参数刻画的整点与之前一样。
首先看斜率的变化，由于是调转 $x,y$ 轴，斜率应该变为原来的倒数，即斜率变为 $\frac{m}{a}$，即应该交换 $a,m$。
接下来看 $b$，原来表示的是 $x=0$ 处的截距，翻转后应该就是最后一次与水平线的交点（即蓝色箭头所指的位置）到 $x=n$ 的距离。
最后来看 $n$，原来表示的是 $x$ 取值 $[0,n)$ 的一个区间，现在要的是 $y$ 轴上的同意义的一个开区间。注意原图最上面一条水平交线翻转后将扮演新图 $x=0$ 的角色，原来的 $y=0$ 翻转后将被定义为新的 $x=n$，因此 $n$ 的数值就是最后一条交线的 $y$ 值，即 $\lfloor \frac{an+b}{m} \rfloor$。
这样反复迭代，直到红线最高的位置也数不出一个点为止。
由于每迭代一次，$a,m$ 都会辗转取模，因此复杂度是 $log$ 级别的。
```cpp
ll floorsum(ll n, ll m, ll a, ll b) {
    ll ret = 0;
    while (true) {
        if (a >= m) {
            ret += n * (n - 1) / 2 * (a / m);
            a %= m;
        }
        if (b >= m) {
            ret += n * (b / m);
            b %= m;
        }
        ll ym = a * n + b;
        if (ym < m) break;
        n = ym / m;
        b = ym % m;
        swap(a, m);
    }
    return ret;
}
```

## $a,b$ 可能为负的情况。
$a$ 为负：把 $a \times i$，全部加上 $|a| \times (n-1)$，
此时 $a \times i$ 恰好变为逆序的 $|a| \times i$，成为正系数形式，把加的部分扣到 $b$ 里面去。
$b$ 为负：其实与正时一样，一上来先平移 $m$ 的倍数，使其为正数，后面就没区别了。

---
title: "拉格朗日插值"
catagory: otherMath
---

刻画一个 $n$ 次多项式，可以用 $n$ 个系数，也可以用 $n+1$ 个点。
如果已知 $n+1$ 个点的位置，可以推断其他 $x$ 对应的 $y$。
如果已知 $(x_0,y_0)(x_1,y_1)(x_2,y_2)...(x_n,y_n)$，现在要求 $x$ 处的 $y$ 值。
由于已知上述 $n+1$ 个点，则方程可以表示为：
$y=y_0\frac{(x-x_1)...(x-x_n)}{(x_0-x_1)...(x_0-x_n)}+y_1\frac{(x-x_0)...(x-x_n)}{(x_1-x_0)...(x_1-x_n)}+...+y_n\frac{(x-x_0)(x-x_1)...}{(x_n-x_0)(x_n-x_1)...}$。
容易验证，当 $x=x_0$ 时，第一项分子等于分母，结果为$y_0$；后面分式的分子存在 $x_0-x_0$，因此为 $0$。
同理对于其余的 $x_i$，也有类似结论。
将其整理一下，为 $y=\sum y_i\prod_{j\ne i} \frac{x-x_j}{x_i-x_j}$。
所以只需要将 $x$ 代入上式，即可求得对应的 $y$。
对每个 $y_i$，后面乘积一共有 $n$ 项，一共有 $n+1$ 个 $y_i$，复杂度为 $O(n^2)$。

特别地，如果 $x_i$ 的取值是连续的，则相邻两个连乘号的分母变化是可以 O(1) 计算的。
比如从 $x_i$ 到 $x_{i+1}$ 时：
分子左侧多加入一个 $x-x_i$，右侧减少一个 $x-x_{i+1}$。
分母左侧多加入一个 $x_{i+1}-x_0$，右侧减少一个 $x_i-x_n$。
所以处理出第一项的分子分母系数后，之后的计算可以 $O(1)$ 完成，如果不预处理逆元，需要多个 $log$。

当然也可以直接考察第 $i$ 项：
$y_i\prod_{j\ne i} \frac{x-x_j}{x_i-x_j}=(-1)^{n-i} y_i \frac{\prod_{j\ne i} x-x_j}{i!(n-i)!}=(-1)^{n-i} y_i \frac{\prod x-x_j}{i!(n-i)!(x-x_i)}=(-1)^{n-i} \frac{y_i}{i!(n-i)!} \frac{\prod x-x_j}{(x-x_i)}$
左侧 $(-1)^{n-i} \frac{y_i}{i!(n-i)!}$ 与 $x$ 无关，可以打包。右侧分子是对所有项求乘积，与 $i$ 无关，可以一次性算出。在 $x$ 范围不是很大时，可以预处理分母的逆元，复杂度 $O(n)$。
```cpp
ll interpolate(ll d[], int n, int x) {
    ll fz = 1, ret = 0;
    for (int i = 0; i <= n; i++) fz = fz * (x - i) % mod;
    for (int i = 0; i <= n; i++) ret += d[i] * fz % mod * inv[x - i] % mod * ifac[i] % mod * ifac[n - i] % mod * (n - i & 1 ? -1 : 1);
    return (ret % mod + mod) % mod;
}
```
在 $x$ 范围很大时，无法预处理分母逆元，不能全部乘到一起，可以预处理分子的前后缀，复杂度还是 $O(n)$。
```cpp
ll interpolate(ll d[], int n, int x) {
    ll ret = 0;
    L[0] = R[n] = 1;
    for (int i = 0; i < n; i++) L[i + 1] = L[i] * (x - i) % mod;
    for (int i = n; i > 0; i--) R[i - 1] = R[i] * (x - i) % mod;
    for (int i = 0; i <= n; i++) ret += d[i] * L[i] % mod * R[i] % mod * ifac[i] % mod * ifac[n - i] % mod * (n - i & 1 ? -1 : 1);
    return (ret % mod + mod) % mod;
}
```
如果确定某个计算通项满足多项式，则可以先求出插值系数，然后插值计算 $x$ 大项。

普通的积分一般把区间 $l\sim r$ 区间的函数值处理成 $f(\frac{l+r}{2})$，面积近似为 $f(\frac{l+r}{2})(r-l)$。
但是实践发现，直线的近似不如二次函数，辛普森积分即是采用二次函数逼近：
设中点 $m=\frac{l+r}2 \rarr 4m^2=(l+r)^2$。
二次方程为 $y=ax^2+bx+c$。
$\begin{cases}
al^2+bl+c=f(l) \\
am^2+bm+c=f(m) \\
ar^2+br+c=f(r)
\end{cases}$
$s=\int_l^r ax^2+bx+c=\frac{a}{3}x^3+\frac{b}{2}x^2+cx|_l^r=\frac{a}{3}(r^3-l^3)+\frac{b}{2}(r^2-l^2)+c(r-l)$
$=\frac{r-l}{6}(2a(r^2+rl+l^2)+3b(r+l)+6c) \\
=\frac{r-l}{6}((ar^2+br+c)+(al^2+bl+c)+a(r^2+2rl+l^2)+2b(r+l)+4c) \\
=\frac{r-l}{6}((ar^2+br+c)+(al^2+bl+c)+4am^2+4bm+4c)\\
=\frac{r-l}{6}(f(l)+f(r)+4f(m))$

以上是得到了二次逼近的积分表达式，接下来是设定积分步长。自适应积分通过设定积分精度，自动判定是否需要继续细分积分区间，判定依据是 $\int_l^r f(x)=\int_l^m f(x)+\int_m^r f(x)$。
如果等式左右侧相差小于设定的精度，就可以停止细分，否则递归对左右侧进行积分。

```cpp
double f(double x) { return (c * x + d) / (a * x + b); }
double simpson(double l, double r) {
    double mid = (l + r) * 0.5;
    return (r - l) * (f(l) + f(r) + 4 * f(mid));
}
double calc(double l, double r) {
    double s = simpson(l, r), mid = (l + r) / 2;
    if (fabs(simpson(l, mid) + simpson(mid, r) - s) < eps) return s;
    return calc(l, mid) + calc(mid, r);
}
```

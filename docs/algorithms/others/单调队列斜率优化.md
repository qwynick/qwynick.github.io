# 单调队列斜率优化

## 单调队列优化
一般来说转移是逐步从一侧到另一侧，转移方程中转移的代价的计算关于 $i,j$ 独立，但是转移范围有限。
即满足 $dp_i=dp_j+f(i)+g(j)$。此时可以分离变量 $dp_i=(dp_j+g(j))+f(i)$，这样转移的时候有 $dp_i=max\{dp_j+g(j) | j<i\}+f(i)$。即将 $dp_j+g(j)$ 整体作为转移基础即可，而 $f(i)$ 又是独立于转移点的，最后直接加即可。
一般来说此类题不能从任意点转移，要求越靠后的 $i$，所能转移的 $j$ 也越靠后。即 $i<=j+d$，或者更广义地可以表示为某个单调函数的函数值之差不超过 $d$。
此时如果一个转移点 $b$ 在转移点 $a$ 的右侧且更优，那么 $a$ 就无意义，因为 $a$ 转移比较差且会先失效，不知如只保留 $b$。
所以有意义的转移点集一定是从左到右越来越差的（但有效期越来越长）。用一个双端队列维护即可。
队头是最优转移，但会最先过期。

## 斜率优化
一般来说转移是逐步从一侧到另一侧，转移方程中转移的代价关于 $i,j$ 不独立。
即满足 $dp_i=dp_j+f(i,j)$。此时不能直接分离变量，但是如果 $f(i,j)=g(i)h(j)$，那么可以通过斜率优化处理。
比如要最小化 $dp_i=dp_j+(i-j)^2+C$，拆开括号：
$dp_i=dp_j+i^2-2ij+j^2+C$，稍加整理：
$dp_i=dp_j+j^2-2ij+i^2+C$。
$i^2+C$ 与转移点无关，要最小化 $dp_j+j^2-2ij$。
对于所有的转移点 $j<i$，如果把 $(j,dp_j+j^2)$ 看成平面上的点，那么转移的结果就是过这个点且斜率为 $2i$ 的直线在 $y$ 轴的截距。我们需要在所有的转移点中找一个截距最小的。
![图片](https://img2024.cnblogs.com/blog/3629076/202607/3629076-20260703155835940-1787140926.png)

上图黑色代表转移点，对于某个特定斜率的红线，要求最小的截距，实际就是从下向上第一次靠上黑点。
很显然，有效的黑点应该构成一个下凸壳。当红线斜率变大时，用到的转移点会向右。在本例中，红线斜率 $2i$ 越来越大，用到的凸壳上的点会不断向右。具体判定为，当红线的斜率大于两个相邻黑点的斜率时，转移点右移会更好，原来的的点可以舍弃。
通过最优转移点计算出 $dp_i$ 后，继续将其加入平面上，由于 $i$ 是目前最大的，所以新加点在最右侧，如果不凸（比如新增图中蓝点），就把尾巴上的点弹出，可以用叉积判段凸性。
在此问题中，转移点单向右移，新加的点又一定在末尾，维护凸性也是弹出末尾，所以一个双端队列就能维护凸壳。

回到一般的情况 $dp_i=dp_j+f(j)+g(i)h(j)$，可以把 $h(j),dp_j+f(j)$ 看作平面上的点，$-g(i)$ 看作斜率，找最小的截距。然后新加点也是用于更新凸壳。如果 $g,h$ 是单调函数，那就直接双端队列维护即可：因为斜率单调变化，用到的点也单调变化；而新加点的横坐标也单调变化。
如果不满足单调性，可以用李超树寻找特定斜率的最优转移点，再维护新点在各个区域的贡献。

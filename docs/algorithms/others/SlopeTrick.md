# SlopeTrick

**如果 $dp$ 的状态呈现凸性，且可以表示为若干线段，则可以维护线段拐点而非线段上各点。**
实现需要左右两个堆，分别维护最小平台左侧和右侧的拐点。

## https://atcoder.jp/contests/abc217/tasks/abc217_h Snuketoon
很容易想到 $dp$，用 $dp_{i,j}$ 代表第 $i$ 事件时停在 $j$ 的最小代价。
对于第 $0$ 类操作，$dp_{i,j}=min_{j-dt\le k\le d+dt}(dp_{i-1,k})+max(0,x-j)$；
对于第 $1$ 类操作，$dp_{i,j}=min_{j-dt\le k\le d+dt}(dp_{i-1,k})+max(0,j-x)$。
注意到两部分都是凸的，且第二部分斜率为 $±1$。
第一部分实际上是衡量可以转移到 $j$ 的范围，在其中找到最小的。换个角度，也可以记录最小的 $dp$ 值能转移到的位置。随着时间增加 $dt$，会向两侧延展，所有的拐点都会推向两边。
第二部分实际上是一个拐折现，以操作 $1$ 为例，类似于一个 $ReLU$ 函数。如果拐点在最小平台的右侧，对最小平台以及最小值无影响；如果在最小平台中间，最小平台缩短，但最小值不变；如果在最小平台左边，最小值被提升 $x-l$，最小平台左移一段。

第二部分操作需要不断维护最靠近最小平台的拐点位置，可以用堆来完成。具体操作为：
- 如果拐点在最小平台右侧：直接将拐点插入 $R$；
- 如果拐点在最小平台中间：直接将拐点插入 $R$，$R.top()$ 受到改变；
- 如果拐点在最小平台左边：最小值被提升 $x-l$，最小平台左移一段，将 $L.top()$ 压入 $R$。
对于操作 $0$ 同理。
注意，对于第一部分平台的延展和拐点的顶开，可以采用延迟标记，即 $L$ 中的实际位置都需要减 $T$，因为只要他在 $L$ 里面，随着时间的流逝都会一直往左顶；同理 $R$ 中的实际位置都需要加 $T$。在存入数据的时候，存入左侧都需要加 $T$，存入右侧都需要减 $T$。

此题有一个 trick，由于移动距离不能超过 $T$，所以并不是所有的拐点都能转移，可以加一个限制，在每一轮为 $LR$ 压入 $0$，使得转移点在 $-T \sim T$ 之间。

## https://www.luogu.com.cn/problem/P4331 Sequence
给你一个序列 $A$，要求选一个递增序列 $B$，最小化 $\sum |A_i-B_i|$。
很容易想到 $dp$，用 $dp_{i,j}$ 代表处理完前 $i$ 个数，且 $B_i=j$ 的最小代价。
$dp_{i,j}=\min_{k \le j}(dp_{i-1,k})+|A_i-j|$；
$dp_{1,j}=|A_1-j|$ 是凸函数，凸函数的前缀最小也是凸函数（一直变小或者后部分拉平），所以上式第一部分为凸函数；而后一部分显然是凸函数，所以两部分相加也是凸函数。
因此可以用 slope trick 维护。
假定现在左堆维护了斜率小于 $0$ 的拐点，右堆维护了斜率大于 $0$ 的拐点，新来一个 $A_i$，如果：
- $A_i<L.top()$：最低平台被抬高且左移。
- $A_i>R.top()$：$B_i$ 直接取到 $A_i$，最低平台移到 $A_i$。
- $A_i$ 居中：$B_i$ 直接取到 $A_i$，最低平台缩为 $A_i$。
可以发现，只需要按 $L.top()$ 分界。
- $A_i<L.top()$：最低平台被抬高且左移一格，$R \leftarrow L.top()$，再把 $A_i$ 入左堆 $L.push(A_i),L.push(A_i)$。
- $A_i>=L.top()$：最低平台缩为 $A_i$，$L \leftarrow A_i,R \leftarrow A_i$。
从上面的操作可以看出，右堆的数据从来没用过，只需要维护左堆。

一个图如果取掉任何一条边都是连通的，则这个图是边双连通的。
一个图如果取掉任何一个点都是连通的，则这个图是点双连通的。

分量的定义与强连通分量类似，为极大导出子图。

## 边双连通分量
边双连通分量很像强连通分量，只不过由于边是双向的，所以只存在树边和返祖边。（有向图中的横叉边成为树边，有向图中的前向边变为返祖边）。
所以只要连接的点能去到更早的，都可以连回去，不用判是否在栈里。
此外，由于边是双向边，所以如果一条边连回父节点，需要确保其不为来时的边。
如果某个点无法往前跳，就形成了一个边双连通分量。
```cpp
void dfs(int node, int pid) {
    dfn[node] = low[node] = ++ts;
    sk.push(node);
    for (auto [nxt, id] : g[node]) {
        if (!dfn[nxt]) mk[id] = true, dfs(nxt, id);
        if (id != pid) low[node] = min(low[node], low[nxt]);
    }
    if (low[node] == dfn[node]) {
        ++bcc;
        vector<int> tmp;
        while (true) {
            int now = sk.top();
            tmp.push_back(now);
            sk.pop();
            bel[now] = bcc;
            sz[bcc]++;
            if (now == node) break;
        }
        res.push_back(tmp);
    }
}
```

## 点双连通分量
点双连通分量有点像边双连通分量，只存在树边和返祖边。但是由于是移除点，所以不能连续跳（会出现跳到移除的点再继续跳的情况）。
对于每个结点，遍历其子节点：
- 如果一个邻点未被访问过，直接访问，此时更新当前点能去到的最高结点。
检查如果该子节点能去到的的最高点不大于自己（无其他边连到自己，或者最高只能连到自己），那么当前点和子节点构成一个双连通分量，且当前点是割点。
- 如果一个邻点已被访问过，且这邻点不是父节点，那么更新当前点能去到的最高结点为 $low_u=min(low_u,dfn_v)$。这里不能用 $low_v$，因为这样会用到从 $v$ 继续向上跳的结果，跨过了 $v$。
特别地，根节点为割点的条件是至少有两个子节点，如果只有一个，那么删掉根之后不会有分离块。此外，如果根节点是孤立点，也是一个双连通分量。
```cpp
void dfs(int node, int fa) {
    dfn[node] = low[node] = ++ts;
    sk.push(node);
    int son = 0;
    for (auto nxt : g[node]) {
        if (!dfn[nxt]) {
            int tp = sk.top();
            dfs(nxt, node);
            son++;
            low[node] = min(low[node], low[nxt]);
            if (low[nxt] >= dfn[node]) {
                cut[node] = true;
                ++bcc;
                vector<int> tmp{node};
                while (sk.top() != tp) {
                    tmp.push_back(sk.top());
                    sk.pop();
                }
                res.push_back(tmp);
            }
        } else if (nxt != fa)
            low[node] = min(low[node], dfn[nxt]);
    }
    if (fa == -1 && son <= 1) cut[node] = false;
    if (g[node].empty()) {
        bcc++;
        res.push_back({node});
    }
}
```
这里虽然得到了割点和点双连通分量，但是结构比较复杂，往往需要结合圆方树才能发挥更大的作用。

## 圆方树
在圆方树中，原结点都是以圆点的形式出现，而每发现一个双连通分量，就建立一个方点，当前双连通分量上各个结点都连到这个方点上。因此，极限情况下，结点数达到 $2N-1$。
```cpp
void dfs(int node, int pre) {
    dfn[node] = low[node] = ++ts, sk.push(node);
    for (int nxt : g[node]) {
        if (!dfn[nxt]) {
            dfs(nxt, node);
            low[node] = min(low[node], low[nxt]);
            if (low[nxt] >= dfn[node]) {
                g2[node].push_back(++bcc);
                while (true) {
                    int now = sk.top();
                    sk.pop();
                    g2[bcc].push_back(now);
                    if (szb[now] >= szb[hv[bcc]]) hv[bcc] = now;
                    szb[bcc]++;
                    sz[bcc] += sz[now];
                    if (now == nxt) break;
                }
                if (szb[bcc] >= szb[hv[node]]) hv[node] = bcc;
                sz[node] += sz[bcc];
            }
        } else
            low[node] = min(low[node], dfn[nxt]);
    }
}
```
代码中，`g2[node].push_back(++bcc);` 就是创建方点的过程。一开始让 $bcc=n$，即在圆方树中，前 $n$ 号结点就是原图的结点。
对双连通分量中各个点，`g2[bcc].push_back(now);` 将双连通分量中除最上面一个点外的其余点全部挂在新建的方点上。
将双连通图转换为圆方树之后，就能用大量高效的树操作了。比如上述代码中 `sz,szb` 分别代表原始结点总数、圆方树节点总数。处理出重儿子之后，就可以采取重链剖分进行各种操作了。

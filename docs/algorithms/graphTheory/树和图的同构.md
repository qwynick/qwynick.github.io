一般直接对树进行哈希，然后比较哈希值。

## 有根树
可以递归从子树的哈希值得到整个树的哈希值。
由于每个结点各个子树并无先后顺序，所以设计的哈希函数必须要对各个子节点等权或者按某种固定的顺序进行加权。
一个直接的想法是按子树哈希值排序后进行多项式加权。这样如果两个结点的子树哈希值集合一样，通过排序后一一对应，按特定的多项式加权后也是一样的。
一个更直接的做法是不用考虑子节点的顺序，直接对各个子节点的权值进行一次变换并求和（显然不能异或）。
```cpp
ull shift(ull x) {
  x ^= mask;
  x ^= x << 13;
  x ^= x >> 7;
  x ^= x << 17;
  x ^= mask;
  return x;
}
void dfs(int node, int pre) {
    hs[node] = 1;
    for (int nxt : g[node])
        if (nxt != pre) {
            dfs(nxt, node);
            hs[node] += shift(hs[nxt]);
        }
}
```
其中 mask 是某个随机数。
这样变换的结果与原值在加法下关联非常弱，不容易冲突。

最终只需要比较根节点的哈希值即可。如果要更确定一些， 也可以把所有的哈希值排序后对比。

## 无根树
如果给定的树是无根的，可以先做一次树哈希，之后再换根即可求出所有点作为根的哈希值。
如果两棵树是一样的，那么所有点作为根后算得的哈希值集合应该完全一致。
由于初始求子树哈希值时，$hs_{node}=1 + \sum shift(hs_{nxt})$。
现在换根，需要把父节点作为上部子树的哈希值给到子结点，其需要用父节点作为向下子树的哈希值，扣除当前子节点的贡献，即 $hs_{node}-shift(hs_{nxt})$。
```cpp
void dfs2(int node, int pre, ull v) {
    if (node != 1) hs[node] += shift(v);
    for (int nxt : g[node])
        if (nxt != pre) dfs2(nxt, node, hs[node] - shift(hs[nxt]));
}
```

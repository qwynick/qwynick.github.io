# 有负环的最小费用最大流

如果有负环，那么出于最小费用考虑，会尽量流满。
但是把所有负环全部流满可能流会不平衡，所以需要参照上下界网络流，在最小费用的前提下让流回到平衡。

所以分为以下几个步骤：
- 对于非负边权，直接正常处理。对于负边权，首先假定负边权的流全部流满，同时记录一下各个点的净流入量，并计算一下费用；为了确保流平衡，需要连一条反向的，容量相等费用相反的边，在无法平衡时实现退流。
- 补充辅助源汇点。对于净流出的边，给他连一条到辅助汇点的容量为净流出量、代价为 $0$ 的边；对于净流入的边，给他连一条辅助源点来的容量为净流入、代价为 $0$ 的边；
- 这样构建的网络所有边权都非负，不存在负环。由于是有源汇问题，可以由真实汇点向真实源点连一条容量无限的边，转为无源汇问题。对上述网络求最小费用最大流，由 $T \rightarrow S$ 的流量即为当前可行流中 $S \rightarrow T$ 的流量，总费用即为当前可行流的费用。
- 断开所有的辅助边，再由真实源点向真实汇点求最小费用最大流，并把前后两次的结果加起来，即得最终结果。

注意，此问题虽然也用辅助网络求最大流，但并不要求最大流等于所有流出之和。
在上下界最大流问题中，如果最大流不等于流出之和，说明有的点的接受的净流入量无法流出（辅助源点流不满），或者有的发出的净流出量无法从上游点获取（辅助汇点流不满）。
而在此问题中，由于强制流的流量正好等于反向退流的容量，所以一定能平衡。
其实，如果不断开辅助边，也是可以的，因为：
- 对于辅助源汇点，其一定是满流，所以与之相关的边都无法增广。
- 对于真实源汇点 $T \rightarrow S$ 的无限流量零费用边，这个求 $S \rightarrow T$ 的费用流完全用不到；$S \rightarrow T$ 的容量为在求辅助源汇最大流时得到的源到汇的真实流量（表观为真实汇到真实源，实际意义代表真实源到真实汇，其流量实质是平衡源汇间的超额流量，转为无源汇问题，详见上下界网络流文章）。
如果不断开辅助网络，在最后一次在真实源汇点之间求最小费用最大流时，最大流会计入 $S \rightarrow T$ 那部分零费用的边，从而得到正确的流量。但是费用需要强制流满负边权、平衡流量、最终最大流三部分合并计算费用。

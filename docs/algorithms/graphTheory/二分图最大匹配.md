根据 Berge 引理，可以通过不断找增广路得到最大匹配。其直观思想为如果有一个匹配图 $M'$ 比 $M$ 大 $1$，直接对两图选中的边取异或，结果即为增广路。当然，异或的结果可能是很多条不相交的路径，但是总结果会加 $1$。

## Kuhn
最基本的是 Kuhn 算法，其原理为不断寻找增广路，当不存在增广路的时候，就达到了最大匹配数。

如果把二分图分成左右两边，考虑从左边开始寻找增广路，此时有两种情况：
- 找到某个右侧的点没有用过，直接匹配成功
- 右侧的点被另外的左侧点匹配了。尝试松掉这对匹配，但为了不减小匹配数量，左侧点需要能另外找一个右侧点配对。
第二种情况为了实现“解绑”，需要记录与右侧各个点匹配左侧点的编号。尝试释放掉这条边后，必须从左侧点开始增广出一条可行的匹配关系，这是一个递归过程。可以标记一下已经访问的点，再次访问无意义，以控制复杂度。

每次增广复杂度为 $O(E)$，最多增广 $V$ 轮，复杂度为 $O(VE)$。
```cpp
struct Kuhn {
    vector<int> g[N];
    int match[N], n, m;
    bool vis[N];
    bool dfs(int node) {
        for (int nxt : g[node])
            if (!vis[nxt]) {
                vis[nxt] = true;
                if (match[nxt] == -1 || dfs(match[nxt])) {
                    match[nxt] = node;
                    return true;
                }
            }
        return false;
    }
    int run() {
        fill(match, match + m, -1);
        int ret = 0;
        for (int i = 0; i < n; i++) {
            fill(vis, vis + m, false);
            if (dfs(i)) ret++;
        }
        return ret;
    }
    void add(int u, int v) { g[u].push_back(v); }
    void clear() {
        for (int i = 0; i < n; i++) g[i].clear();
    }
} mm;
```

## Hopcroft
更高效的做法是采用 Dinic 的思想，并利用二分图的特殊性质进行操作，即 Hopcroft-Karp 算法。
按照 Dinic 的思想，每一轮先标记距离，在增广的时候，必须要求距离合适。
可以证明，增广轮次不会超过 $\sqrt{V}$，每一轮最坏需要遍历所有边，故总复杂度为 $E\sqrt{V}$。
```cpp
struct Hopcroft {
    vector<int> g[N];
    int ma[N], mb[N], dis[N], n, m;
    bool bfs() {
        queue<int> q;
        bool ok = false;
        fill(dis, dis + n, -1);
        for (int i = 0; i < n; i++)
            if (ma[i] < 0) {
                q.push(i);
                dis[i] = 0;
            }
        while (!q.empty()) {
            int now = q.front();
            q.pop();
            for (int nxt : g[now])
                if (mb[nxt] == -1)
                    ok = true;
                else if (dis[mb[nxt]] == -1) {
                    dis[mb[nxt]] = dis[now] + 1;
                    q.push(mb[nxt]);
                }
        }
        return ok;
    }
    bool dfs(int node) {
        for (int nxt : g[node])
            if (mb[nxt] == -1 || dis[node] + 1 == dis[mb[nxt]] && dfs(mb[nxt])) {
                mb[nxt] = node, ma[node] = nxt;
                return true;
            }
        dis[node] = -1;
        return false;
    }
    int run() {
        fill(ma, ma + n, -1), fill(mb, mb + m, -1);
        int ret = 0;
        while (bfs()) {
            for (int i = 0; i < n; i++)
                if (ma[i] == -1 && dfs(i)) ret++;
        }
        return ret;
    }
    void add(int u, int v) { g[u].push_back(v); }
    void clear() {
        for (int i = 0; i < n; i++) g[i].clear();
    }
} mm;
```

## 二分图匹配的可行边
先考虑左右完美匹配的情况，设左边的点是 $a,b,c,...$，右边的点是 $...x,y,z$。假定有 $a \rightarrow x,b \rightarrow y,c \rightarrow z...$。
如果一条边属于最大匹配中的边，那自然是可行边。
如果一条边 $e_{a \rightarrow y}$ 没在最大匹配中，如果强行选中而不影响最大匹配数的话，则要求 $b \rightarrow x$ 存在。
根据二分图匹配的增广过程，按照未匹配边从左向右，匹配边从右向左，因此在残量图中，只有由左向右的未匹配边和由右向左的匹配边。
如果 $b \rightarrow x$ 存在，叠加上尚未匹配的边 $a \rightarrow y$、已匹配的边（反向） $x \rightarrow a,y \rightarrow b$ 可得 $a \rightarrow y \rightarrow b \rightarrow x \rightarrow a$，可得 $a,y$ 属于同一个强连通分量。
所以对于完美匹配的情况，确认未匹配的边是否为可行边，只需要按未匹配边从左向右，已匹配边从右向左构图，看未匹配边两端是否在同一个强连通分量即可。

如果不是完美匹配，连接 $a \rightarrow y$ 后，因为有悬空点，所以并不强制找到 $b \rightarrow x$ 的增广路，只需要 $b$ 找到任意一个未匹配的右侧点 $w$ 或者让任意一个未匹配的左侧点 $d$ 找到 $y$ 即可。为了统一处理悬空点，可以补充源汇点，把左侧未匹配点集中到源点上，把右侧未匹配点集中到汇点上，实际上就是转化为最大流模型。
由源点向左侧点连边，所有右侧点连边到汇点，先求出最大流。
如果原始的边有流，必然是可行边，现在考虑没有流的可行边。
对于未匹配边 $e_{a \rightarrow y}$，如果存在 $b \rightarrow x$ 的增广路，按照之前完美匹配的分析，$a,y$ 会形成强连通分量。
对于未匹配边 $e_{a \rightarrow y}$，如果存在 $b \rightarrow w$ 的增广路，其中 $w$ 为未匹配点，则存在 $w \rightarrow T$ 的路径；由于 $x$ 已经匹配，存在 $T \rightarrow x$，叠加最大流中反向边 $x \rightarrow a,y \rightarrow b$，则会出现 $a \rightarrow y \rightarrow b \rightarrow w \rightarrow T \rightarrow x \rightarrow a$，即 $a,y$ 处于同一个强连通分量。所以存在如果 $a,y$ 处于同一个强连通分量，则 $e_{a \rightarrow y}$ 是可行边；反之如果 $a,y$ 不处于同一个强连通分量，则 $e_{a \rightarrow y}$ 不是可行边。
同理对于未匹配边 $e_{a \rightarrow y}$，如果存在 $d \rightarrow x$ 的增广路，其中 $d$ 为未匹配点，也能得出一样的结论。
**总结：在残量网络中跑强连通分量，如果一条边在最大匹配中，或者两个点在一个强连通分量里，是可行边。**

## 二分图匹配的关键边
先考虑左右完美匹配的情况。
如果一条边不属于最大匹配中的边，那自然不成立。
如果一条边 $e_{a \rightarrow x}$ 在最大匹配中，如果不用这条边不影响最大匹配数的话，说明残量网络中有 $x \rightarrow a$ 的增广路，再考虑最大匹配中 $a,x$ 匹配，残量网络中存在 $x \rightarrow a$，合起来存在 $a \rightarrow x \rightarrow a$，$a,x$ 在同一个强连通分量里。反之如果不存在 $a \rightarrow x$ 的增广路，则 $a,x$ 不在一个强连通分量中。
所以对于完美匹配的情况，确认已匹配的边为关键边只要看两端是否在同一个强连通分量即可。

如果不是完美匹配，断开 $a \rightarrow x$ 后，不能存在任何一个未匹配的 $w$，使得存在 $a \rightarrow w$ 的增广路；也不能存在任何一个未匹配的 $d$，使得存在 $d \rightarrow x$ 的增广路。同理可以补充源汇点，使得一侧的未使用点集中到源/汇上，用最大流求解。
由源点向左侧点连边，所有右侧点连边到汇点，求出最大流。
如果某条边无流量，必然不会是关键边，现在考虑有流的边。
对于匹配边 $e_{a \rightarrow x}$，如果存在其他的 $a \rightarrow x$ 增广路，按照之前完美匹配的分析，会形成强连通分量。
对于匹配边 $e_{a \rightarrow x}$，如果存在 $a \rightarrow w$ 的增广路，其中 $w$ 为未匹配点，则存在 $w \rightarrow T$ 的路径；由于 $x$ 已经匹配，存在 $T \rightarrow x$，叠加最大流中反向边 $x \rightarrow a$，则如果存在 $a \rightarrow w$，会出现 $a \rightarrow w \rightarrow T \rightarrow x \rightarrow a$，即 $a,x$ 处于同一个强连通分量。所以存在如果 $a,x$ 处于同一个强连通分量，则 $e_{a \rightarrow x}$ 不是关键边；反之如果 $a,x$ 不处于同一个强连通分量，则 $e_{a \rightarrow x}$ 是关键边。
同理对于匹配边 $e_{a \rightarrow x}$，如果存在 $d \rightarrow x$ 的增广路，其中 $d$ 为未匹配点，也能得出一样的结论。
**总结：在残量网络中跑强连通分量，如果一条边在最大匹配中，且两个点不在一个强连通分量里，是关键边。**

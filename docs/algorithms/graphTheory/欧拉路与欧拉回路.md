## 无向图
无向图的欧拉路是指经过所有的边恰好一次；欧拉回路还要求回到原点。
- 欧拉回路存在充要条件是不存在奇数度的点，且所有度数非 $0$ 的点连通。
- 欧拉路存在的充要条件是奇数度的点不超过 $2$ 个，且所有度数非 $0$ 的点连通。

必要性
把欧拉路拉直，除了首末点度数为奇数外，其余点每经过一次度数加 $2$。特别地，如果起点就是终点，所有点的度数都是偶数。
充分性
相当于消圈的过程。

考虑有两个奇数度的点的无向图的存在欧拉路的情况，下面给出一个构造性证明。
注意一个事实，图中只有两个点的度数为奇数，选定起点后，剩下那个点就是终点。此时在图中游走，第一次遇到死路就是在那个终点。
这是因为除了那个终点外，所有点的度数都是偶数，因此能进就能出。
在回溯的时候，可能某个节点 $u$ 还有别的分叉可以进入别的环路，同样由于所有点的度数都是偶数，所有的点能入就能出，没有死路，直到回到节点 $u$ 为止。
这其实暗含了一个事实，如果我们遍历的时候不是先去向终点，而是先绕这个环，就能访问更多的点。
注意到另一个事实，从任何一个点出发进行深搜，一定会遍历到所有的点。也就是说，我们如果遇到环就先绕环，可以访问完所有结点，最后到达终点。
于是我们不要在进入时记录访问结果，而在回溯时记录访问结果，依照前面的分析，就得到了一个反序的欧拉路。
欧拉回路的情况本质上是一样的，当任意选定一个点作为起点后，终点也就是这个点本身。

```cpp
void dfs(int u) {
    while (p[u] != g[u].end()) {
        auto [v, e] = *p[u]++;
        if (mk[e]) continue;
        mk[e] = true;
        dfs(v);
        resv[tot] = v, rese[tot++] = e;
    }
}
```
## 有向图
有向图要求稍多：
- 欧拉回路存在充要条件是所有点都满足 入度=出度，且所有度数非 $0$ 的点连通。
- 欧拉路存在的充要条件是所有点 入度=出度，或者最多有两个点其中一个点出度比入度大 $1$，另一个点出度比入度小 $1$，且所有度数非 $0$ 的点连通。其实形态上就是在欧拉回路的基础上最多多两条尾巴，一个进入欧拉回路，一个离开欧拉回路。

必要性
把欧拉路拉直，除了首末点出入度差 $1$ 外，其余点有进就有出，度数相等。特别地，如果起点就是终点，所有点的出度都等于入度。
充分性
相当于消圈的过程。

考虑有两个点出入度不等的有向图存在欧拉路的情况，下面给出一个构造性证明。
注意一个事实，只能以出度多 $1$ 的点作为起点，只能以入度多 $1$ 的点作为终点。此时在图中游走，第一次遇到死路就是在那个终点。
这是因为除了那个终点外，所有点的入度等于出度，因此能进就能出。
在回溯的时候，可能某个节点 $u$ 还有别的出路进入别的环路，同样由于所有点的入度等于出度，所有的点能入就能出，没有死路，直到回到节点 $u$ 为止。
这其实暗含了了一个事实，如果我们不是先去向终点，而是先绕这个环，就能访问更多的点。
注意到另一个事实，从起点出发进行深搜，一定会遍历到所有的点。也就是说，我们如果遇到环就先绕环，可以访问完所有结点，最后到达终点。
于是我们不要在进入时记录访问结果，而在回溯时记录访问结果，依照前面的分析，就得到了一个反序的欧拉路。
欧拉回路的情况本质上是一样的，当任意选定一个点作为起点后，终点也就是这个点本身。

```cpp
void dfs(int u) {
    while (p[u] != g[u].end()) {
        auto [v, e] = *p[u]++;
        dfs(v);
        resv[tot] = v, rese[tot++] = e;
    }
}
```

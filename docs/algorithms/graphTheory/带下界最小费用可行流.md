# 带下界最小费用可行流

以 https://www.luogu.com.cn/problem/P4043 支线剧情为例

与带上下界可行流一样，先把下界流满，但此时结点的流不一定平衡。
如果某个点 $u$ 流入过剩，如果要平衡，需要在真实的网络流中超额流出，因此可以补充一个虚拟源点，由虚拟源点向 $u$ 连边，推送该超额流量，该超额流量就能在真实网络中流动。
如果某个点 $v$ 流出过剩，如果要平衡，需要在真实的网络流中超额流入，因此可以补充一个虚拟汇点，由 $u$ 向虚拟汇点连边，推送该超额流量，该超额流量就能在真实网络中流动。

为了平衡流，流量可以以一定开销从一个结点流到另一个结点，也可以免费流回开头，补充这些边即可。

最后求一次从虚拟源点到虚拟汇点的最小费用最大流，即流满辅助边（使得节点流平衡）时的最小费用即可。
费用流的费用加上强制流的下界费用就是总费用。

```cpp
void solve() {
    int n, k, a, b, sum = 0;
    cin >> n;
    MCMF mf(n + 2);
    int src = 0, dst = n + 1;
    for (int i = 2; i <= n; i++) mf.add(i, 1, inf, 0);
    for (int i = 1; i <= n; i++) {
        cin >> k;
        out[i] += k;
        while (k--) {
            cin >> a >> b;
            out[a]--, sum += b;
            mf.add(i, a, inf, b);
        }
    }
    for (int i = 1; i <= n; i++)
        if (out[i] > 0)
            mf.add(i, dst, out[i], 0);
        else if (out[i] < 0)
            mf.add(src, i, -out[i], 0);
    mf.run(src, dst);
    cout << mf.cost + sum;
}
```

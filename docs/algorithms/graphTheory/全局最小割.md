# 全局最小割

全局割是指找一个边集，使得将这些边删去后，原图会断开成两个部分。
全局最小割是在这些边集中，边权和最小的。

最暴力的就是任选起点，求 $V-1$ 次最大流。因为最小割会将图分为两部分，因此每个点都一定能找到一个点处于割开的另一部分。所以求 $V-1$ 次最大流一定能找到解。
考虑用预流推进算法，复杂度 $O(V^4)$ 或者 $O(V^3\sqrt{E})$。

Stoer-Wagner 算法可以在 $O(V^3)$ 的时间复杂度求出全局最小割。
其思想是，如果有两个点 $s,t$，他们要么在最小割的同一侧，要么在最小割的不同侧。
- 如果他们在不同侧，他们之间的割就是全局最小割；
- 如果他们在同侧，那么可以直接把他们合并为同一个点，不影响最小割。

问题关键是，直接求任意两个点的最小割也是比较麻烦的，单次硬求的复杂度会去到 $O(V^3)$。

但是本问题我们要求的是全局的最小割，某一对特定的 $s,t$ 并不感兴趣，只要随便求出一对 $s,t$ 的最小割，即可进行合并，合并 $V-1$ 次就变成一个点了。

现在考虑有 $V$ 个点的图，怎么求出其中一个最小割。
- 可以先随便选取一个点，放入 $S$ 集合，此时其余各个点到 $S$ 集合的边权和为 $w_u=\sum_{u \notin s,v \in s} g_{uv}$。找到这里面 $w_i$ 最大的那个点，将其加入 $S$ 集。
- 更新其他点到 $S$ 集的总权重。
反复操作，直到所有点都进入 $S$ 集，最后进入的两个点即为 $s,t$，最后一次的权重即为 $s,t$ 的最小割。每次找到权值最大的点需要 $O(V)$，一共需要找 $V$ 次，复杂度 $O(V^2)$。

算法的正确性，待补。

每缩点一次，求一次当前点集的某对点集 $s,t$ 的最小割，当点缩为一个时，即得到最后结果。缩点 $V-1$ 次，总复杂度 $O(V^3)$。

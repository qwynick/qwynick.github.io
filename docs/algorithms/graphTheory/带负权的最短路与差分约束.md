## 带负权的最短路
如果一个图中的边存在负权，不能用 dijkstra 求解，但可以用 floyd 求解；如果存在负环，则不能用 floyd 求解。
此时可以用 Bellman-Ford 求解，如果经过 $V-1$ 轮松弛操作后还能继续松弛，则说明有负环。因为任意两个点的最短路不可能超过 $V-1$ 条边。如果第 $V$ 轮无法松弛则找到了最短路。复杂度 $O(VE)$。
实际操作中可以采用 spfa 求解，加速松弛，但最坏复杂度还是 $O(VE)$。

首先设置起点 $dis_s=0$，入队列，其余点 $dis_i=inf$，然后反复做以下操作：
- 出队 $u$，检查邻边 $e_{u \rightarrow v}$，如果发现 $dis_v > dis_u + w_{uv}$，则对 $dis_v$ 进行松弛：
  - 设置 $dis_v = dis_u + w_{uv}$。由于 $v$ 被松弛了，可以用它继续松弛别的点，因此如果 $v$ 不在队列中，让 $v$ 入队。
- 按 Bellman-Ford 的思想，任意点至多在第 $V-1$ 轮被松弛到最短，如果第 $V$ 轮还在松弛，就说明有环。所以可以记录入队次数，只要入队达到 $V$ 次就有负环。但是这样判环稍慢。
由于无负环情况下，一个点的最短路最多经过 $V-1$ 条边，更快的做法是记录最优路径经过的边数，当路径边数达到 $V$ 即可结束。

## 最短路与最长路
此外，由于 Bellman-Ford 和 spfa 是基于松弛操作，还可以用来求解最长路。
在前述最短路求解中，如果有边 $w_{uv}$，意味着存在一个对 $v$ 的约束 $dis_v \le dis_u + w_{uv}$，如果发现当前 $dis_v > dis_u + w_{uv}$，就可以把 $v$ 拉回到 $dis_v = dis_u + w_{uv}$。

如果现在改变一下给定约束的意义，如果有边 $w_{uv}$，意味着存在一个对 $v$ 的约束 $dis_v \ge dis_u + w_{uv}$，如果发现当前 $dis_v < dis_u + w_{uv}$，就可以把 $v$ 放逐到 $dis_v = dis_u + w_{uv}$。即求出了各个点的最长路。

## 差分约束
现在给定一个系统，给定若干个约束条件：
- $dis_v \le dis_u + w_{uv}$
- $dis_v \ge dis_u + w_{uv}$
注意，上面的不等式也可以通过移项变为类似的形式。
为方便统一运算逻辑，松弛操作可以统一为一个方向，比如将 $dis_v \ge dis_u + w_{uv}$ 变为 $dis_u \le dis_v - w_{uv}$。这样的约束其实就是最短路，但是边权可能为负数，不能用 dijkstra 跑，但可以用 spfa。

如果 spfa 能够终止，就找到了一个可行解。
由于整个松弛过程都是在用约束条件 $dis_v \le dis_u + w_{uv}$ 把不合理大的数字 $dis_u$ 往下拉到刚刚合理，因此这个可行解得到的是各个点的最大解。
显然，除了起点，初始值需要设置到极大。

反过来，如果把约束条件都改为
- $dis_u \ge dis_v - w_{uv}$
- $dis_v \ge dis_u + w_{uv}$

那么跑 spfa 求得的是最长路。整个过程都是在用约束条件 $dis_v \ge dis_u + w_{uv}$ 把不合理小的数字 $dis_v$ 往上推到刚刚合理，实际是求得的各个点的最小解。
显然，除了起点，初始值需要设置到极小。

以 https://www.luogu.com.cn/problem/P5960 为例。
```cpp
void solve() {
    int n, m, a, b, c;
    cin >> n >> m;
    while (m--) {
        cin >> a >> b >> c;
        g[a].emplace_back(b, -c);
    }
    queue<int> q;
    fill(in + 1, in + n + 1, true), fill(dis + 2, dis + n + 1, -1 << 30);
    for (int i = 1; i <= n; i++) q.push(i);
    while (!q.empty()) {
        int now = q.front();
        q.pop(), in[now] = false;
        for (auto [nxt, len] : g[now])
            if (dis[nxt] < dis[now] + len) {
                dis[nxt] = dis[now] + len;
                cnt[nxt] = cnt[now] + 1;
                if (cnt[nxt] == n) {
                    cout << "NO\n";
                    return;
                }
                if (!in[nxt]) q.push(nxt), in[nxt] = true;
            }
    }
    for (int i = 1; i <= n; i++) cout << dis[i] << ' ';
}
```

李超树

工具函数，计算某一对kb在某位置的函数值。y=kx+b
```cpp
double calc(int id, int x) { return l[id].first * x + l[id].second; }
```

如果新插入的kb在mid位置计算的结果大于已经保存的kb在mid位置的计算结果，将新插入的kb保存到当前位置作为最优解。同时后续的更新交给原来的kb。
判断待更新的kb在左侧极限的计算结果是否优于当前保存的，如果优于就没必要继续更新了，因为由于是直线，中间区间也一定被压制。
判断待更新的kb在右侧极限的计算结果是否优于当前保存的，如果优于就没必要继续更新了，因为由于是直线，中间区间也一定被压制。
考虑直线的性质，每次更新只可能走一条，不可能两条路都走，否则就盖过seg[node]了。
id可能不被记录，也可能记录在第一次胜利的位置。
```cpp
void update(int node, int l, int r, int id) {
    int mid = l + r >> 1;
    if (calc(id, mid) > calc(seg[node], mid)) swap(id, seg[node]);
    if (calc(id, l) > calc(seg[node], l)) update(node << 1, l, mid, id);
    if (calc(id, r) > calc(seg[node], r)) update(node << 1 | 1, mid + 1, r, id);
}
```

某个位置在所有可能的kb组合中的最大值，只需要用递归过程中所有的kb组合跑一遍，取最大的即可。
能被记录到seg[node]，要么这个点本身没数据，要么是到目前为止此处最大的kb。把路径上所有点都跑一下一定不会漏掉。
```cpp
double query(int node, int l, int r, int x) {
    double ret = calc(seg[node], x);
    if (l == r) return ret;
    int mid = l + r >> 1;
    if (x <= mid) return max(ret, query(node << 1, l, mid, x));
    return max(ret, query(node << 1 | 1, mid + 1, r, x));
}
```

# 可持久化并查集

可持久化并查集以可持久化数组（可持久化线段树）为基础，在可持久化数组上做按秩合并的并查集。
每次访问一个位置都需要在树上跑一轮，因此数组访问是logn复杂度。

先完成update和query这一对可持久化数组的基本操作。

每个位置需要记录两个数据，p父节点是谁，sz集合大小是多少。其实与按秩合并所记录的数据是一样的，只不过此时在树上。
```cpp
void update(int od, int& nw, int l, int r, int pos, pii val) {
    info[nw = ++cnt] = info[od];
    if (l == r) {
        info[nw].p = val.first;
        info[nw].sz = val.second;
        return;
    }
    int mid = l + r >> 1;
    if (pos <= mid)
        update(info[od].ls, info[nw].ls, l, mid, pos, val);
    else
        update(info[od].rs, info[nw].rs, mid + 1, r, pos, val);
}
```

正常查询，没什么说的。
```cpp
int query(int node, int l, int r, int pos) {
    if (l == r) return node;
    int mid = l + r >> 1;
    if (pos <= mid) return query(info[node].ls, l, mid, pos);
    return query(info[node].rs, mid + 1, r, pos);
}
```

接下来是正式的并查集操作。
在原始的并查集中，直接p[i]=i即可，在此处，需要通过build来初始化fa节点为自己，同时将sz置为1。
```cpp
void build(int& node, int l, int r) {
    node = ++cnt;
    if (l == r) {
        info[node].p = ++id, info[node].sz = 1;
        return;
    }
    int mid = l + r >> 1;
    build(info[node].ls, l, mid), build(info[node].rs, mid + 1, r);
}
```

寻找某个版本ver的pos所属的集合。
第一步查询以ver为根的数的pos结点，并取出其父节点。相当于原来访问的p[node]。
如果p[node]==node那么自己就是根了，否则就继续在当前版本找find(p[node])。可以类比普通的并查集。
不过这里返回的node是动态开点编号，而非结点值。
```cpp
int find(int ver, int pos) {
    int node = query(ver, 1, n, pos), fa = info[node].p;
    return fa == pos ? node : find(ver, fa);
}
```

合并两个点所在的集合，首先找到他们在当前版本的根。
如果是同一个点，那么就不用操作了。
如果不是同一个点，进行按秩合并，将a指向b。
第一个update，将nda结点的父节点指定为ndb，sz设置为0。
第二个update，将ndb结点的父节点指定为自己，然后sz为两个集合之和。
nda/ndb是动态开点编号，info[node].p是指向的结点值。
```cpp
void merge(int a, int b, int rid) {
    int nda = find(root[rid - 1], a), ndb = find(root[rid - 1], b);
    if (nda == ndb) {
        root[rid] = root[rid - 1];
        return;
    }
    if (info[nda].sz > info[ndb].sz) swap(nda, ndb);
    update(root[rid - 1], root[rid], 1, n, info[nda].p, {info[ndb].p, 0});
    update(root[rid], root[rid], 1, n, info[ndb].p, {info[ndb].p, info[nda].sz + info[ndb].sz});
}
```

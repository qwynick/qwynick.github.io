# 树链剖分

按子树大小确定轻重儿子。从任何节点向父节点走，每走一条轻边，节点数至少翻倍，所以最多走logn次轻边。结合线段树区间处理重链，可以实现树上路径维护。

先可以用树链剖分求LCA。

第一遍dfs确定节点深度，以及子树大小，重儿子。
```cpp
void dfs1(int node, int pre) {
    fa[node] = pre, dep[node] = dep[pre] + 1;
    sz[node] = 1;
    int heavy = 0;
    for (int nxt : g[node])
        if (nxt != pre) {
            dfs1(nxt, node);
            sz[node] += sz[nxt];
            if (sz[heavy] < sz[nxt]) heavy = nxt;
        }
    hv[node] = heavy;
}
```

第二遍dfs求出LR范围，优先走重儿子，这样重链上的点是连续编号的。并记录每个点所属的重链起点tp。
对于重儿子，将当前所属链的链头传下去；对于轻儿子，轻儿子自己是链头。
```cpp
void dfs2(int node, int tp) {
    top[node] = tp, L[node] = ++ts, idx[ts] = node;
    if (hv[node]) dfs2(hv[node], tp);
    for (int nxt : g[node])
        if (nxt != fa[node] && nxt != hv[node]) dfs2(nxt, nxt);
    R[node] = ts;
}
```

求LCA，如果两个点所属链不一样，判断链头的深度，将链头深的一个跳掉。
同一个链的两个点，浅的一个就是结果。
```cpp
int lca(int a, int b) {
    while (top[a] != top[b]) {
        if (dep[top[a]] > dep[top[b]]) swap(a, b);
        b = fa[top[b]];
    }
    return dep[a] < dep[b] ? a : b;
}
```

这就是用树链剖分求LCA。

如果需要真正维护链路信息，需要将链路拆分成若干段链，一般结合线段树。

更新：
只要ab不在一条链，先更新链头深的一个点到其链头区间。
如果ab在一条链，更新a到b的信息。
```cpp
void update(int a, int b, Tag c) {
    while (top[a] != top[b])
        if (dep[top[a]] > dep[top[b]]) {
            update(1, 1, n, L[top[a]], L[a], c);
            a = fa[top[a]];
        } else {
            update(1, 1, n, L[top[b]], L[b], c);
            b = fa[top[b]];
        }
    if (L[a] > L[b]) swap(a, b);
    update(1, 1, n, L[a], L[b], c);
}
```

查询：
只要ab不在一条链，先查询链头深的一个点到其链头区间。
如果ab在一条链，查询a到b的信息。
如果链条区间合并存在顺序，需要注意。
```cpp
Info query(int a, int b) {
    Info ret;
    while (top[b] != top[a]) {
        if (dep[top[a]] < dep[top[b]]) swap(a, b);
        ret = ret + query(1, 1, n, L[top[a]], L[a]);
        a = fa[top[a]];
    }
    if (L[a] > L[b]) swap(a, b);
    ret = ret + query(1, 1, n, L[a], L[b]);
    return ret;
}
```

update和query就是标准的线段树操作。

# 笛卡尔树

笛卡尔树是一个二叉树，根是最小的(当然也可以设置为最大的)，其左右子结点分别是其左侧最小的数和右侧最小的数。
所以笛卡尔树的结构有点类似于堆，即从根开始，越往叶结点走越小。
同时，笛卡尔树的中序遍历就是原数组。

笛卡尔树的构建是依序完成的。假定前 $n$ 个数已经构建了一个笛卡尔树，现在新来一个结点 $x$。
这个 $x$ 显然在树上是最靠右的结点，具体位置可能有三种：
- 他是最小的，此时他作为根，左儿子就是原来的根；
- 他是比第 $n$ 个数大的，此时他应该作为第 $n$ 个结点的右儿子。
- 他大小适中，此时他应该沿着 $n$ 号结点向根寻找，找到一个合适的结点 $y$（恰比自己小），将自己作为 $y$ 的右儿子，同时将 $y$ 原来的右子树作为自己的左子树，这样大小关系满足、中序关系也满足。

从上面的步骤可以看出，我们需要维护从根开始的一个右子结点序列（递增），新加入结点在这个序列上找自己的位置，一个栈即可完成。
不考虑重复的数字，这个位置的元素 $y$ 应该比新加的数小一些，但前一个元素 $z$ 应该比新加的数大一些。
此时可以把 $x$ 设置为 $y$ 的右孩子，同时把 $z$ 子树挂到 $x$ 的左孩子。这样保证了大小关系和中序顺序。
之后把结点 $x$ 入栈，之后再来新的点，就从 $x$ 向前找位置。

```cpp
    stack<int> sk;
    fill(l, l + n, -1), fill(r, r + n, -1);
    for (int i = 0; i < n; i++) {
        cin >> d[i];
        while (!sk.empty() && d[i] < d[sk.top()]) l[i] = sk.top(), sk.pop();
        if (sk.empty())
            root = i;
        else
            r[sk.top()] = i;
        sk.push(i);
    }
```

典型应用：求两个位置之间的最小值，结果就是 lca 位置的值。

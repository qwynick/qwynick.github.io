点分治通过不断选定重心，将树剖成若干小子树，完成统计。

以长度不超过k的路径条数为例。

记录从重心到当前结点的距离，压入d数组，便于后面统计。
同时计算以重心为根划分的各个子树（块）的大小，便于下一轮分治传参。
```cpp
void dfs2(int node, int pre, ll dis) {
    d.push_back(dis), sz[node] = 1;
    for (auto [nxt, len] : g[node])
        if (!vis[nxt] && nxt != pre) {
            dfs2(nxt, node, dis + len);
            sz[node] += sz[nxt];
        }
}
```

排序后双指针狂出d[l]+d[r]不超过k的，此时从l+1到r都可以与l配对，共r-l个。
```cpp
ll calc(vector<ll>& d) {
    sort(d.begin(), d.end());
    int n = d.size(), r = n - 1;
    ll ret = 0;
    for (int i = 0; i < n; i++) {
        while (i < r && d[i] + d[r] > k) r--;
        if (i >= r) break;
        ret += r - i;
    }
    return ret;
}
```

分治操作，处理node所在的连通块，目前连通块大小为s。
首先通过dfs1找重心，记录每个点的最大子树，使得最大子树最小的点就是重心。
对重心断开后的每颗子树，用dfs2搜集从重心到该子树各个结点的距离。
先扣除子树内部的路径配对数（有效的内部路径在之后的子树划分中会统计）。
将子树的个点距离合并进总集合。
对总集合计算所有可行的距离的配对。此时统计的结果实际上是跨（含）重心结点的线条，内部的已事先扣除。
最终统计的实际上是在重心处被斩掉的路径，所有的合法路径都只会被斩断1次。
之后对各个子树进行递归分治，统计的是子树内部的路径。
```cpp
void dc(int node, int s) {
    int mn = inf, root;
    auto dfs1 = [&](auto& dfs1, int node, int pre) -> void {
        int mx = 0;
        sz[node] = 1;
        for (auto [nxt, len] : g[node])
            if (!vis[nxt] && nxt != pre) {
                dfs1(dfs1, nxt, node);
                sz[node] += sz[nxt];
                mx = max(mx, sz[nxt]);
            }
        mx = max(mx, s - sz[node]);
        if (mn > mx) mn = mx, root = node;
    };
    dfs1(dfs1, node, node);
    //-------------------
    vector<ll> dAll;
    vis[root] = true, dAll.push_back(0);
    for (auto [nxt, len] : g[root])
        if (!vis[nxt]) {
            d.clear();
            dfs2(nxt, root, len);
            ans -= calc(d);
            dAll.insert(dAll.end(), d.begin(), d.end());
        }
    ans += calc(dAll);
    //-------------------
    for (auto [nxt, len] : g[root])
        if (!vis[nxt]) dc(nxt, sz[nxt]);
}
```

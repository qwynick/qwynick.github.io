---
title: "带权并查集与可撤销并查集"
catagory: dataStucture
---

一般并查集：
每个点先指向自己，如果两个集合需要合并，把一个集合的根指向另一个集合的根即可。
为避免出现长链，有两种处理方式：
一、压缩路径，所有查过的点全部指向根。也可以非递归压缩两层。
二、按秩合并，将秩小的指向秩大的。这里秩可以取集合大小，也可以取最长链条长度。
单独使用一个复杂度是均摊logn量级。

带权并查集，除了维护集合的所属关系外，还维护一些相对信息。
相对于普通并查集，每个点额外记录一下其到其父节点的相对权重d。
采取路径压缩，在递归返回的时候，更新当前结点到相对于新父节点（即根）的权重。其值就是自己到原父节点的权重+原父节点到新根的权重。
```cpp
int find(int node) {
    if (node == p[node]) return node;
    int root = find(p[node]);
    d[node] += d[p[node]];
    return p[node] = root;
}
```

可撤销并查集，可以回退合并，但是必须依次序。
很显然不能采取路径压缩，因为全部压缩到一个根之后，无法返回之前的做法。
路径压缩方式没有随意更改边的连接，可以撤销。

找根方式是不断向父节点前进。
```cpp
int find(int node) {
    while (p[node] != node) node = p[node];
    return node;
}
```
合并的时候采取根指向根，所以第一步是先找到根。
根据sz的不同，确定指向方式，由小的指向大的。
如果是同一个根，则不采取实际合并，但需记下这次操作以便撤销。
被合并的sz增加，另一边不用处理不影响查询，但后面撤销时会用。
```cpp
void merge(int a, int b) {
    a = find(a), b = find(b);
    if (sz[a] > sz[b]) swap(a, b);
    sk.emplace(a, b);
    if (a == b) return;
    p[a] = b;
    sz[b] += sz[a];
}
```
撤销的时候如果发现是同样的点，说明没实际合并，直接结束。
否则按合并时的规则撤销，将小的树根指向自己，同时大数sz扣除小树sz。
```cpp
void undo() {
    if (sk.empty()) return;
    auto [a, b] = sk.top();
    sk.pop();
    if (a == b) return;
    p[a] = a;
    sz[b] -= sz[a];
}
```

# 可持久化线段树

每次修改树，都会对修改路径涉及到的点新建节点，由于层数是log级别，所以空间复杂度会Qlog。
不修改的点，沿用之前的结点，从新建的点连一条边过去即可。

这里以查询区间k大为例。
修改某个位置时，新开一个结点存放新的版本信息。默认先把旧版本的左右孩子编号复制给新建的节点，维护的信息（这里是数字个数sum）根据具体情况调整。
根据位置，递归处理左右子树，同样传递老版本的节点编号和新版本的节点编号给下一层。
这里由于很简单，没有写pushup。
```cpp
void update(int od, int& nw, int l, int r, int val) {
    nw = ++tot;
    L[nw] = L[od], R[nw] = R[od], sum[nw] = sum[od] + 1;
    if (l == r) return;
    int mid = l + r >> 1;
    if (val <= mid)
        update(L[od], L[nw], l, mid, val);
    else
        update(R[od], R[nw], mid + 1, r, val);
}
```

查询的位置是从L-R中的第k大数，所以用R扣除L-1的和即可，传入的两个根的版本分别为L-1和R，两个版本之间某个位点i的sum之差即为出现在L-R之间的位点i出现的个数。
如果新旧版本之间mid左侧的位点的个数和已经达到，那么去左边找，否则去右边找。
```cpp
int query(int od, int nw, int l, int r, int k) {
    if (l == r) return ls[l];
    int mid = l + r >> 1;
    if (sum[L[od]] + k <= sum[L[nw]])
        return query(L[od], L[nw], l, mid, k);
    else
        return query(R[od], R[nw], mid + 1, r, k - (sum[L[nw]] - sum[L[od]]));
}
```

很容易参考区间查询线段树，进行区间查询，比如下例，如果当前结点的区间被查询区间完全覆盖，直接返回节点新旧版本计数差即可。
```cpp
pii query(int od, int nw, int l, int r, int a, int b) {
    if (a <= l && b >= r) return {r, sum[nw] - sum[od]};  // return info
    int mid = l + r >> 1;
    pii ret;
    if (sum[L[nw]] != sum[L[od]] && a <= mid) ret = query(L[od], L[nw], l, mid, a, b);
    if (sum[R[nw]] != sum[R[od]] && b > mid) return ret + query(R[od], R[nw], mid + 1, r, a, b);
    return ret;
}
```

## 带修区间k大
如果位置的范围是 $1\sim N$，数字的值域是 $1\sim V$，那么首先按照值域建立线段树，按位置依次构建版本。
当需要改 $d_x=y$ 时，需要将历史版本 $x$ 加入的值 $d_x$ 替换为 $y$。但是这样是不够的，因为后续所有版本都用到了 $d_x$，需要一并修改，这样单次修改的复杂度就变为了 $O(nlogV)$，单次查询保持为 $O(logV)$。
可以参考静态前缀和和动态前缀和，如果是静态前缀和数组，如果对某个位置修改，则后面所有位置都需要修改，复杂度 $O(n)$，单次查询为 $O(1)$。但是如果采用树状数组，则只需要修改 $O(logn)$ 个位置，但是查询也由 $O(1)$ 变为了 $O(logn)$。这里很类似，采用树状数组记录修改信息后，修改的复杂度由 $O(logV)$ 变为 $O(lognlogV)$，同时查询的复杂度也由 $O(logV)$ 变为了 $O(lognlogV)$。
具体而言，对某个位置的数字修改后，依次按照树状数组的逻辑修改特定位置，查询的时候也按照树状数组查询特定位置，则避免了大规模的修改。
这样就以 $O(lognlogV)$ 的复杂度实现了修改。

注意，由于修改的时候需要对一连串的+=lowbit位置进行update，而这个update就是普通线段树的修改，是递归二分叉的。修改的位置是 logn 个，修改的深度是 logV，这也是复杂度的来由。
```cpp
    for (int p = a[i]; p <= n; p += p & -p) update(0, m - 1, sroot[p], sroot[p], d[a[i]], -1);
    d[a[i]] = lower_bound(ls, ls + m, b[i]) - ls;
    for (int p = a[i]; p <= n; p += p & -p) update(0, m - 1, sroot[p], sroot[p], d[a[i]], 1);
```

在查询的时候，当查询某个点时，需要将-=lowbit的位置全部汇总进来。如果只查总数，则没什么好说的，直接依次算再加总即可。但是如果需要在线段树上二分，实际上需要同步对多个位置进行二分。这里可以预提取各个位置的根结点，如果值域需要向左，则所有位置的值域结点都改为左子结点；如果值域需要向右，则所有位置结点的值域结点都改为右子结点。
```cpp
    for (int p = a[i] - 1; p; p -= p & -p) qa[na++] = sroot[p];
    for (int p = b[i]; p; p -= p & -p) qb[nb++] = sroot[p];
    cout << query(0, m - 1, root[a[i] - 1], root[b[i]], k[i]) << '\n';
```
```cpp
int query(int l, int r, int od, int nw, int k) {
    if (l == r) return ls[l];
    int mid = l + r >> 1, ans = cnt[L[nw]] - cnt[L[od]];
    for (int i = 0; i < na; i++) ans -= cnt[L[qa[i]]];
    for (int i = 0; i < nb; i++) ans += cnt[L[qb[i]]];
    if (k <= ans) {
        for (int i = 0; i < na; i++) qa[i] = L[qa[i]];
        for (int i = 0; i < nb; i++) qb[i] = L[qb[i]];
        return query(l, mid, L[od], L[nw], k);
    } else {
        for (int i = 0; i < na; i++) qa[i] = R[qa[i]];
        for (int i = 0; i < nb; i++) qb[i] = R[qb[i]];
        return query(mid + 1, r, R[od], R[nw], k - ans);
    }
}
```

注意，树状数组的更新区间为 $n$，即位置的范围，而非值域。

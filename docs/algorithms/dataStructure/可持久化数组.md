# 可持久化数组

可持久化数组本质上就是用可持久化线段树来实现历史版本数组维护。
单数据修改空间复杂度是log。时间复杂度log

动态开点建树。
```cpp
void build(int& nw, int l, int r) {
    nw = ++tot;
    if (l == r) {
        sum[nw] = d[l];
        return;
    }
    int mid = l + r >> 1;
    build(L[nw], l, mid), build(R[nw], mid + 1, r);
}
```

更新数据。新开一个点，左右子节点直接编号直接复制，然后根据当前需要修改的位置，向左右递归直到特定位置。
```cpp
void update(int od, int& nw, int l, int r, int p, int v) {
    nw = ++tot, L[nw] = L[od], R[nw] = R[od];
    if (l == r) {
        sum[nw] = v;
        return;
    }
    int mid = l + r >> 1;
    if (p <= mid)
        update(L[od], L[nw], l, mid, p, v);
    else
        update(R[od], R[nw], mid + 1, r, p, v);
}
```

根据给定的版本，也就是特定的根，找到需要的位置。
```cpp
int query(int nw, int l, int r, int p) {
    if (l == r) return sum[nw];
    int mid = l + r >> 1;
    if (p <= mid) return query(L[nw], l, mid, p);
    return query(R[nw], mid + 1, r, p);
}
```
